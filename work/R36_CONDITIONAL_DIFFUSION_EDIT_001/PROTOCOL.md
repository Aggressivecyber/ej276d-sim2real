# R36 frozen conditional diffusion edit

The registered R36 task is the scientific definition. One REAL-only denoiser is fitted on the original R33 target/bin/row-ordinal trajectory, at most 2950 batches of 32 and 900 seconds. The source generator remains frozen. No CFM is trained, no target-pair matching is used, and no checkpoint is selected.

The U-Net uses two encoder residual blocks at each of 480/240/120/60 and two decoder residual blocks at 120/240/480, concatenating the corresponding encoder skip after nearest upsampling and a kernel-3 channel conversion. Attention is only between the two encoder blocks at 60 points. All residual block and embedding details, schedules, weights and seeds follow the task. The actual parameter count is saved before the first update. Conditions are log signed Qtotal and signed PSD standardized on the original 18895 supported REAL TRAIN waveforms using sample SD. No clipping or particle label conditioning is used.

Training random draws per batch are PCG64(20261010361): integer t[32] in 1..100, followed by normal float64 epsilon[32,480] cast float32. Initial/final and each batch RNG state/hash are persisted. Model initialization is 20261010360. All coefficients are computed in float64; actual abar is cumprod after beta cap .999.

At inference the fixed source/bin support remains the original unquantized source-Q support, while scalar conditions come from the frozen-G preADC guide. Real control support/conditions come from its own full unquantized guide. Both use t_start=50 with discrete epsilon DDPM posterior, no predicted-x0 clipping, smoothing, projection or charge rescaling. Single original ADC is applied last. Supported invalid Q/conditions stop execution.

PCG64(20261010362) allocates uint64 record seeds in fixed namespaces and order: SOURCE_MAIN 2000, REAL_GUIDE 2000, JOINT8 1024. Original source probes reuse each noise-origin main seed so same source/noise remains the same stochastic edit; guide perturbations reuse the selected main seeds. Every record reconstructs one row-major normal[50,480] float64 matrix cast float32, initial row followed by reverse noise for t50..2. t1 consumes none. Runtime records actual hashes and NumPy versions. Record noise is independent of chunks. The independent CPU process verifies source and real control seeds, noise hashes, conditions, support, exact pre/postADC and base/edit components.

Each new classifier and density slot is saved immediately. The two new evaluation domains are CONDITIONAL_DIFFUSION_EDIT and REAL_GUIDE_EDIT, with the latter using the original RAW REAL-REAL reference-guide 600/250 selection and matching cluster labels; source uses the fixed source 600/250 selection. Old controls and RAW RR are reused without refits. All 20 HGB and 16 density-slot limits include failures. Undefined and lost original BASE density support fail the registered gates.

Guide perturbation is the fixed zero-integral 1mV-RMS sinusoid in 150:400. Conditions, bins and full random matrices are held fixed. Main source parents/composition/weight/order, the original source probes and joint8 are retained. Exact auxiliary preADC and algebraic increments are saved. The edited waveform has no identified physical signal/electronic split; cross-covariance is retained. Neither random repeats, artificial 50-record groups nor two fitted PSD components imply independent acquisitions or particle truth.

Training is one owned Linux worker with PID/nonce/cwd and RSS bound before scientific imports; all generation/evaluation/replay is local CPU4. No migration content tests, installations, EVAL/CAL/new REAL/G4, source relabeling or original-stage writes.
