Existing `.used` files prohibit accidental duplicate submissions. Do not rerun in the sealed directory. These are reproduction instructions, not authorization for extra fits under the completed stage budget.

`TRAIN_PRIVATE.npz` contains original6593/21047 TRAIN and512/599 validation. Sampling uses3753/18895 common-support events. `SHARED_TRAIN_STREAMS_PRIVATE.npz` stores source/REAL/bin/uniform/NCE selections. `TRAINING_RANDOM_STATES.json` records each arm's reset z/white/style streams; hashes and completed-prefix checks distinguish equal prefixes from different total update counts under the wall clock cap. The large complete seeds are passed to PCG64 rather than a uint32 API.

Each arm's `TRANSLATOR.pt`, `STYLE_READER.pt` and `CRITIC.pt` belong to the same selected update. `FINAL_*` are last updates and do not replace selected weights. `OPTIMIZER_SELECTED.pt` and `OPTIMIZER_FINAL.pt` preserve training states. To reconstruct a STANDARDIZED critic, load its original `Critic.net` weights and apply the saved R22 `mu,scale` to original two-channel input first; these constants are intentionally nonpersistent network buffers and are stored separately. The only difference between arms is that input treatment.

`ACTUAL_GENERATION_INPUTS.npz` contains original2000 parent waveforms, source IDs, z/white/style. Each `generated.npz` saves pre/post ADC voltage and functional signal/electronic components. Independent `replay_selected.py` loads saved selected G and actual input, generates all4000 main rows anew, compares ADC before/after and both components plus ID order, and writes `REPLAY_RECEIPT.json`; it reads no REAL/TRAIN waveforms and performs no fit.

`JOINT8_INPUTS_PRIVATE.npz` explicitly reuses R21's original128 parents×8 joint draws. It does not assume the first1024 rows of a merged file are that experiment. `PROBE_INPUTS_CORRECTED.npz` separates source parent, noise origin and reference parent. Fixed-source/noise comparisons use the corrected reference, and current outputs preserve those roles.

Evaluation uses the same old600/250 source/REAL selections, seven HGB views, frozen CAL references and eight TRAIN-defined density bins. Two new arms require14 HGB and at most16 density EM attempts. Old reference metrics and REAL–REAL comparisons are reused rather than refit. Plotting uses only saved waveforms/features/metrics. Complete arrays, IDs, predictions and training streams stay on E/D; `METRICS_COMPACT.json` is the aggregate publication copy.

DEV is historically exposed development data from one acquisition. Artificial50-record groups are not independent collection runs. The underlying G4 source waveform uses total electron/hadron energy deposits and a fixed analytic pulse recipe, not microscopic deposit times. An unpaired distribution match, correlated source/output PSD, or nonzero source sensitivity does not identify the correct eventwise detector mapping.
