# 实测电荷目标：前瞻验收 v5

本版本落实 2026-10-11 用户的明确更正：**实测电荷分布是响应目标；仿真提供随条件变化的趋势，并用于实测不足区域的响应补全。** 对后续新方法，本文与 `PROJECT_ACCEPTANCE_REAL_CHARGE_V5.json` 是当前目标；入口为 `CURRENT_ACCEPTANCE.json`。原 `PROJECT_ACCEPTANCE.md/.json` v4 保持原字节，用于重现 R69 及更早阶段。新目标尚未经过模型验证。

授权原文：“保留实际数据的电荷分布 因为他是真实的 仿真的目的是为了提供一个趋势参考 真实数据可以看作是仿真数据的扭曲，在数据缺少能区通过仿真可以弥补数据不足 所以符合真实电荷分布是我们要保留的”。本修订改变了响应目标的定义；不能把新门称为原逐事件 SOURCE 电荷守恒门，也不追改历史通过/失败。

## 数据与响应目标

1. **实测参照保留。** 合法 REAL 的原身份、原 Q、原权重、共同 ADC 表示与固定分区边界保持。响应拟合只使用获准 TRAIN；DEV/EVAL 和人工缺口留出的 REAL 不进入拟合、选参或检查点选择。原始数据不改写，不把 REAL 电荷谱重权或拉伸到仿真谱。
2. **仿真电荷允许经响应映射改变。** 输入仍为完整仿真波形。保留全部原 SOURCE 父事件、组成、顺序、权重及支持外事件；没有删除、补标签或重抽输入以改善验收的授权。模型输出的 Q 分布应接近实测，而不再逐事件强制等于原仿真 Q。给每个输出保存父 ID、原 Q、独立预测的目标 Q*、preADC Q、canonical ADC Q、所有原始条件和随机流。
3. **同一方法处理两域。** SOURCE 与 REAL 使用相同的公开输入定义、预处理、Q 响应、波形响应、噪声、数值算子和 ADC。禁止用域标记、查表身份或 REAL 旁路制造保持性。REAL 原 Q 是不可改写的参照；同处理 REAL 的分布保持必须由评价证明，不能由结构名或恒等初始化代替。
4. **条件轴明确。** 分布匹配、条件 PSD/峰宽/噪声评价以输出自身 canonical Q 和冻结 REAL 边界归区；内部 Q* 条件、preADC 与 ADC 后归区分别保存。原名义 Q 分区保留用于输入抽样、来源和趋势审计。保存原 bin → Q* bin → preADC bin → ADC bin 的完整迁移、人口与权重；失败和支持外输出仍在总分母内。旧固定输入分区的损失不能直接改名为输出条件损失。
5. **补全的含义。** 在实测有覆盖处拟合原实测电荷谱与条件波形；在稀疏或未观测处，用仿真趋势提出条件响应预测，并单列可验证范围及不确定性。补区样本的使用频率不等于已测真实事件率。Q 是现有电荷/可见能量代理；独立能量标定、入射能量和真实缺区事件率仍为 unknown。

C 中的新实现一致性门定义为 `abs(Q_preADC - Q*) / abs(Q*) ≤ 1e-5`，Q* 必须是由输入和冻结参数提前计算、保存的响应目标，不能定义成输出积分本身；非有限或非正 Q* 记失败。另报告 `Q*/Q_source` 与 `Q_ADC/Q_source`，明确展示电荷响应变化。原“相对原 SOURCE Q ≤1e-5”的物理守恒要求被替换，旧门结果不重评。

Q 的内部算子继续使用现有 480 点共同窗 `sum(x[100:400]) - 3*sum(x[:100])` 及冻结的单位换算。积分器候选 N 与参考 2N 由下一数值协议前瞻固定；中位误差 ≤0.25 LSB、P95 ≤1 LSB 保持，LSB=1/16383 V。非迭代 Q 模块须另有预登记的独立精度参考，不能虚构 N/2N 通过。整个组装方法须同时检查 Q 模块、完整波形数值路径、ADC 量化与重放。

原阶段六门的 BASE 对照、源扰动、时间边界、REAL 控制和报告义务仍沿用 v4 与 R43 定义；本版没有以“仿真只是趋势”为由取消这些要求。若与新目标出现新的实际冲突，须报告具体证据和前瞻修订，不能在观察结果后删门。
