64 个固定父事件的扰动检查仍显示源与随机性会影响输出：固定噪声、置换源条件时，NSF 的平均波形 RMS 改变量为 0.018397 V；固定源、更新随机输入时为 0.010735 V。源 Q 与输出 Q 的 Spearman 相关为 R3B 0.926、NSF 0.915，源 hadron fraction 与输出 PSD 为 0.513、0.435。这些仅是敏感性和关联检查，不证明物理映射正确。

与 2592 条 REAL-fit 的最近邻检查中，各域均无完全相同的最近邻。NSF 到训练库的电压 RMS 距离中位数为 0.004649 V，REAL DEV 为 0.003902 V，R3B 为 0.003446 V。这是描述性检查，不能据此证明没有记忆训练样本。

工程检查通过：小规模非平凡变换的数值逆误差为 6.53e-16，解析 Jacobian log-determinant 与自动微分误差为 3.12e-16。训练后的完整 480 点模型在 2000 条样本上的逆变换最大电压误差为 3.85e-7 V，约 0.00631 nominal ADC 步。新进程重新加载 R3B 和 NSF 后，2000 × 480 个 pre-ADC 数值最大误差为 0，post-ADC 逐值完全一致；没有重新拟合指标。
