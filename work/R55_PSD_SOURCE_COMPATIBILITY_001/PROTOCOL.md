# R55：固定源人口的 PSD 与源谷比例必要条件诊断

本轮由主助手独立执行，无子智能体。R54 已按原 A/B/C 全部失败封存并实际交付；本轮不修改这些结果，不训练或选择新模型。长期目标仍为同一冻结方法满足原 A–F。此前确证的源电荷边缘差异和 Q-only 描述统计尚不能证明固定 HGB 验收不可能。

## 问题、数据与固定终点

检验一个必要条件：在原 2000 SOURCE 身份、顺序、等权重及其允许的输出电荷范围保持时，是否存在任意 signed-PSD 分布，可以同时达到总体 W1≤0.010、原共同 Q1–7 区等权平均条件 W1≤0.010，以及原始 SOURCE purehad Q3/Q4 谷比例增量≤0.020。

仅使用冻结 R54 的 `FEATURES_PRIVATE.npz`、`metrics.json`，原 R46 的 `ACTUAL_GENERATION_INPUTS.npz`、`DEV_SOURCE_METADATA.npz`、分区和谷定义，以及 R54 的源身份回执。REAL 使用原 2000 条共同 ADC 表示后的有效特征。源分组保持未量化输入定义，purehad Q3/Q4 必须仍为 213/181。不得以旧 postADC 的 207/182 替换。所有已暴露 DEV 的使用均披露；不打开 EVAL、不新解码 CAL，也不构造或输出新的评价候选。

固定科学终点为一个稀疏线性规划、一次 `highs-ds` 求解和一次下界证书计算。没有网格、求解器或容差扫描，没有 HGB、密度拟合、响应训练或 ODE 推理。一个低下界只表示本放宽问题未能排除可行性；它不能证明 A–F 可行，更不能作为模型通过。

## 保守的输出电荷与分箱集合

沿用 q=sum(x[100:400])−3sum(x[0:100])，单位 V ns。对每条原始输入，输出 q 允许落在

`[q_source*(1−1e−5)−600/16383−1e−6, q_source*(1+1e−5)+600/16383+1e−6]`。

600 是绝对电荷系数之和。每个采样点留出一整 LSB，覆盖理想半 LSB 舍入及当前 float32 ADC 算术；另留 1e−6 V ns 的浮点余量。原要求的 clip_count=0、有限波形和正电荷仍是必要前提。相比采用理想半 LSB，这个范围有意更宽，只用于诊断下界。输入幅值及 q 定义差异将在进程内检查，以确认这一余量适用。

采用原 `edges_logQ`；可能的输出区间包括下方支持外、八个原区和上方支持外。区间相交判断额外放宽 1e−10 的 logQ 边界余量，绝不把支持外事件强行归入边缘区。原始源谷分组固定在输入 q，而不跟随输出分箱迁移。

## 线性放宽及其必要性

按“允许的输出分箱集合、是否属于原 purehad Q3/Q4”合并同类源事件。每组 g 的质量固定为 n_g/2000；变量 m_gj 允许它在可达输出区 j 间作分数分配。分数分配是求下界时的数学放宽，不能作为实际源重加权或新候选。

网格只取全部固定 REAL PSD 值与两个固定谷区间端点的并集，不作可调分辨率选择。相邻网格点之间，REAL 的经验 CDF 恒定。c_gjk 表示组 g、输出区 j 的联合 CDF 在第 k 个区间的平均值；要求随 k 单调，且 0≤c_gjk≤m_gj。所有真实输出分布均满足这些约束。网格外的非负 W1 积分不计入目标，只会进一步降低下界。

令 s_j=sum_g m_gj、C_jk=sum_g c_gjk，并引入条件 CDF 平均值 F_jk。真实分布满足 C_jk=s_j F_jk。使用由可达源数量给出的固定质量上下界 l_j、u_j，将此乘积放宽为四条 McCormick 线性不等式；F 保持 [0,1] 且单调。共同 Q1–7 每区仍要求至少 40/2000 的质量。八区以外和 Q8 不增加条件 PSD 限制，但继续进入总体 CDF。

目标为区间宽度乘总体 CDF 平均值差绝对值之和。Jensen 不等式保证它不大于任何对应真实输出的总体 W1。共同 Q1–7 的条件 CDF 采用相同 Jensen 下界，并限制七区之和≤7×(0.010+1e−6)。

源谷约束使用谷内最后一个网格区间的 CDF 平均值减去第一个区间的平均值，再对该原始源组及全部可达输出区求和。该差不大于原闭谷区间的真实概率质量，因此限制它≤组质量×(原 BASE 谷比例+0.020+1e−6) 是保守放宽，不能误作原谷概率的精确重建。

原峰位、密度拟合、峰宽、源秩、完整波形、噪声、HGB、REAL 控制及 D/E 等条件均未加入此诊断。它们被放宽而非取消原验收。任何原 A–F 合格的输出，必须先满足本必要问题；本问题的可行解不保证这些未加入的条件。

## 数值证书与判定

源质量、条件经验 CDF、原 BASE 比例和网格宽度按保存值构造有理数系数。所有等式展开为两条不等式；所有变量有 [0,1] 界。转为 float64 稀疏矩阵时，每条右端项按系数舍入误差的最坏 [0,1] 影响向外放宽，目标系数向下舍入。保存实际求解矩阵、目标及舍入说明。

求解器的 primal objective 不能单独作为不可能性证据。用实际返回的非正不等式对偶 y，按精确二进制有理数计算

`L = y^T b + sum_j min(0, c_j − (A^T y)_j)`。

由于 x_j∈[0,1]，即使数值对偶有残差，上式仍是所保存放宽 LP 的有效下界。对偶正项先截为零，只会取另一个允许的 y。用精确有理数计算并保存证书分子/分母、下界的向下浮点表示和检查回执；不以“优化成功”替代该证书。

只有有效证书严格超过 0.010+1e−6，才报告这些必要条件在本冻结经验人口上的冲突。否则报告“该放宽诊断不能排除可行性”；如无有效对偶或求解失败，报告“证据不足”。不改变原 0.010 或 0.020 验收线，诊断中的额外余量只会使冲突更难证明。
