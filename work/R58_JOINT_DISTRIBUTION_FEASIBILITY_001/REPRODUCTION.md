# R58 reproduction

This is one finite-family statistical feasibility calculation on legal TRAIN data. It creates no teacher waveform and trains no neural response. It does not change the original A-F acceptance, the fixed evaluation SOURCE identities/weights, or previous failed results.

`config.json` fixes 512 REAL quantile atoms, 64 SOURCE midrank segments, ten original Q regions, the h==1 valley constraint, one HiGHS dual-simplex LP, and numerical feasibility tolerances. `INPUT_BINDING.json` binds the original TRAIN, frozen constants, frozen REAL TRAIN valley definition and R57 descriptors. Only `target` is decoded from the TRAIN archive for observed baseline means; SOURCE and REAL PSD/Q/identity/composition descriptors come from the bound R57 archive. No validation, DEV, EVAL or CAL arrays are decoded.

`joint_core.py` conserves exact integer mass from every REAL parent to the 512 quantile segments, then computes segment means. Every SOURCE is retained in a group identified by its original Q region, h==1 flag and global PSD midrank segment. The LP variable is parent-count mass from each group to each target PSD atom. Row sums preserve original SOURCE mass and column sums preserve the fixed target marginal. Group-conditional laws are lifted uniformly back to original parents; the h flag never changes or becomes a REAL particle label.

The sole objective maximizes SOURCE/output midrank covariance. With fixed marginals the rank variances are constant. The exact conditional W1 constraints use the union of candidate atoms and all original REAL PSD values in each bin, plus CDF recursion. The valley inequalities use the unchanged frozen interval endpoints. This restricted-family numerical optimum is not a universal upper bound or infeasibility certificate for A-F.

Run `numeric_worker.py` once through `linux_supervise_post.py numeric_worker.py` in its registered server directory. `linux_owned_worker.py` binds the actual process identity before imports. The supervisor applies CPU12 and RSS48GiB, checks for other project science, and has null time/iteration/output budgets. Preserve the `.used` marker and all original receipts. Any separately authorized replay must use a new directory and the recorded dependency versions.

`LP_PRIVATE.npz` contains the complete sparse matrices, objective, RHS, solution and solver dual values when available. Bounds are x>=0 for the first `x_variables`, and 0<=CDF/slack<=1 thereafter. `TARGET_ATOMS_PRIVATE.npz` retains every original REAL integer contribution. A successful solve saves `JOINT_LAW_PRIVATE.npz`; failed solves retain input groups in `POPULATION_PRIVATE.npz`. `verify_joint.py` reloads saved arrays and independently recomputes exact SciPy W1, source/target marginals, valley probabilities and weighted rank moments without another LP solve. Negative probabilities are reported, not truncated into validity.

`ADC_INPUT_BOUNDS.json` always reports free-PSD charge limits. For a nonnegative solved law, `ADC_BOUND.json` and `ADC_BOUND_PRIVATE.npz` additionally report joint probability mass whose short/long integrals cannot fit the ADC range for any baseline mean in the observed REAL TRAIN range. This necessary condition does not construct a waveform, ensure correct noise, or predict the frozen DEV acceptance rate.

`RESULT.json`, `INDEPENDENT_VERIFICATION.json` when available, four PNGs, original/native solver receipts, resource receipts and actual Git/D delivery receipts document the result. Full waveform response, same-treated-REAL, density peaks/widths, source perturbation, numerical replay, downstream utility and FULL/GAP remain responsibilities of a future frozen neural method under the original protocol.
