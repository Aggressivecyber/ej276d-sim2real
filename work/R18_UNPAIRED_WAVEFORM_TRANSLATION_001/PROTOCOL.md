# R18: complete source-waveform to measured-style response

Frozen before the first parameter update. One arm, no DEV recipe selection. A full physical 480-point G4-derived clean waveform and its own peak-normalized shape enter a small residual 1D U-Net (16/32/64 channels, four bottleneck dilation blocks 1/2/4/8). Two decoder skip levels retain full source timing. Neither four scalar conditions, PDG, event ID, nor an independent target-density sample replaces this waveform input. The deterministic residual is unconstrained by the obsolete 0.15 cap; the physical ADC range is applied only at final generation. A source-conditioned convolutional random branch receives eight standard-normal latent coordinates and 480 white samples: 1 mV white plus a bounded 5 mV learned term. The learned random branch can also alter its conditional mean; it is not asserted to be a pure variance-only intervention or calibrated photon statistics.

The source is the existing R2 cache: 6593 fit, 1599 internal validation. Exactly 512 validation parents are selected by an input-ID hash before training. REAL fit is R14's 21047 QC rows and the unchanged 599 internal validation rows. DEV contains the unchanged 2000 G4 parents and 2000 measured rows. No EVAL or CAL waveform values, raw long waveform decoding, new G4, or source-provenance audit. DEV clean waves are reconstructed with the already-used R2 analytic formula from saved EE/hadron deposit totals. This does not introduce missing microscopic deposition times.

Independent source and target RNG streams sample within the same uniformly selected common frozen R3B 8-logQ bin. This is population conditioning, not event pairing. All outside-support and invalid rows remain in the final population report. Source target MSE pairing is absent.

LSGAN waveform matching is combined with three-level within-image patch contrastive content loss (12 temporal positions per level, temperature 0.07), real-domain identity, squared source logQ change, global Q rank, *within the same narrow frozen charge bin only* PSD rank, and joint physical-feature/pooled-shape sliced-Wasserstein matching. PSD pairs with source separation at most 0.005 are excluded, and violations are normalized by the actual eligible pair count. PSD hinge desired margin is min(0.04,0.3 times source difference), allowing a common or charge-dependent offset; Q hinge uses logQ separation >0.05 and margin min(0.2,0.5 times separation). Exact weights: GAN 1, content 1, identity 2, logQ-relative 0.5, Q-rank 2, PSD-rank 5, domain-SW 2, positive-charge penalty 1. These constraints are hypotheses, not physical calibration.

Adam lr 0.0002, betas (0.5,0.999), gradient norm cap 5, batch 32; one G and one D update per round, at most 4000 rounds/1200 s. Seeds and all weights/optimizer/RNG state are saved. TF32 off, deterministic algorithms, four CPU threads, CUDA training. Last/selected/initial weights are distinct. A fixed 512-source/599-REAL validation uses a fixed z/white sequence at step0 and every250. J = equal-weight common-charge-bin standardized marginal physical-feature W1 + equal-weight common-charge-bin pooled-shape SW + 0.5 mean absolute source logQ change + 2 within-charge PSD rank violation. Generated validation rows are conditioned by their SOURCE charge bin, REAL by its observed charge. Bins without both populations are explicitly reported and never replaced by a full-population selection score. Global population mixture differences are a separate final outcome. Physical scales/projections derive from TRAIN only. Lowest J selects; ties choose earlier. Validation controls selection only, never adds training targets. Neither learned critic scores nor DEV metrics select the checkpoint.

Final CPUfloat32 inference saves 2000 complete source waves, actual z/white, parent IDs and pre/post-ADC waves, mean and random branches. Source clean is separately named from historical noisy SIM. All population metrics use first100 baseline, Qfast100:150, Qtotal100:400, 1 ns, signed PSD=1-Qfast/Qtotal, the historical 14-bit [-0.5,0.5] V ADC. No HC deletion. Six historical waveform/local C2ST views plus observed Q/PSD use fixed R7 600/250 pools and 500 artificial-group bootstraps: source, translated and same-N TRAIN–DEV REAL–REAL, 21 HGB fits maximum. Train/holdout scores retained; near0.5 is not an equivalence guarantee. At most16 new 8-bin width descriptions (source and translated); REAL description is reused. Qualified support gaps are retained.

Source preservation is independently described by paired Q/PSD correlation, charge migration, pureEE/purehad/mixed and PDG strata. Pure composition is from deposited energy, not incident particle. TRAIN cache has explicit PDG. DEV 2112/non2112 labels can infer22 only using the previously bound R2 CSV evidence that it contained PDG22/2112 only; that inference is distinguished from explicit per-event PDG storage. REAL density peaks remain descriptive, not particle truth.

832 source probes: 128 same input/noise, 128 cyclic source exchanges (no fixed points), 128 fixed-source different noises, 64 each of amplitude0.5/1.5, and 64 each of five analytic EE/hadron-shape interpolations at matched source charge. Same actual noise is reused across relevant counterfactuals. These interpolations are not new G4 events. Nonzero output sensitivity is not physical correctness. Separate128 parents receive eight noises (1024 rows), composition-stratified by fixed input hashes then filled to128. Within-parent PSD SD/range and crossing both sides of the frozen old TRAIN valley are reported without per-parent GMMs. Source-conditioned broadening cannot be excused by matching REAL's overall two peaks.

A fresh process uses only selected weights, saved source and actual random inputs to replay all2000 main outputs, comparing pre/post ADC values. No target/train data are needed. Resource: science1800 s including failures/replay, RSS/GPU allocated4 GiB, one process at a time, local outputs256 MiB, executor stop08:31:26.541622 UTC. Normal copy/transfer receipts suffice; no migration equality tests or repeated input hashes. Scientific residuals do not trigger a second recipe.

Method inspirations: [CUT](https://arxiv.org/abs/2007.15651) for multilayer source-content contrast; [CycleGAN](https://arxiv.org/abs/1703.10593) for the underconstrained unpaired-mapping problem. This is a purpose-built 1D implementation, not an original-paper reproduction or proof of a unique detector response.
