# R47 后的执行方向：同时处理已有噪声与响应学习失真

R47 已完成登记的五个诊断分类器，未新增响应训练、ODE 或密度拟合。SOURCE 与 REAL DEV 的电荷分布确实不同，KS 为 0.2685；但固定 charge-only 分类器的 SOURCE / LONG 留出 BA 分别为 0.586 / 0.590，95% 区间均跨过 0.60。按预定规则，这项判别证据为 uncertain。它既不是原二维评价器的下界，也不足以据此宣布原总体目标不可能达到。

更明确的证据来自 REAL 输入的处理路径。基线 RMS 均值由 RAW 的 0.645992 mV，经初态变为 1.193383 mV，再到 SHORT 的 1.234196 mV 和 LONG 的 1.537006 mV。学习后的 ACF1 距离也进一步增加。SOURCE 路径则从零基线变为初态 0.998213 mV，再降至 SHORT / LONG 的 0.685231 / 0.697719 mV。同一方法对两个输入域表现不同，不能把问题概括成“Gaussian 太大”，也不能推断删掉保存的 Gaussian 项就会得到一个有效新模型。

基线局部分类器使用幅度归一化后的形状、ACF 和频谱，故其较低 BA 不否定 RMS 幅度变化。四个功能分量与全部六个带符号交叉项共同还原实际方差；负交叉项必须保留。这只是已执行路径的统计与代数描述，未识别独立物理信号、电子噪声或因果贡献。

## 第二阶段的具体设计要求

保留原 A–F、原始源权重和全部总体报告。此前关于验收口径的可选问题尚无答复，因此继续沿用原标准；不将它当作降低标准的授权，也不将本轮 uncertain 结果当作必须修改口径的证明。

下一方法只围绕一个问题设计：让完整 SOURCE 波形驱动的响应变换能够处理输入中已经存在的噪声，同时使同一处理路径对 REAL 输入保持统计稳定。方案必须在训练前写清以下内容：

1. **已有噪声如何处理。** 使用现有 TRAIN 基线信息建立输入噪声估计与输出噪声处理的固定定义；需要的独立性、平稳性或频域假设明确列出。不得把保存的 S/G/F/R 功能项直接当成物理真值，也不得沿用加噪后再删某项的事后做法。
2. **完整响应如何学习。** 全部 480 点源输入进入响应路径；源 Q/PSD、组成与父事件关联继续按原规则检验。避免原 R34 的硬分段修补；REAL 输入经过同一已定义算子，不能用域标签另设回退路径来美化控制。
3. **只检验一个主机制。** 一个固定主候选配一个等数据、等更新预算的对照；两者的差别应对应“已有噪声的处理”，不能同时比较任意网络、不同源人口和不同训练长度。实际时间、参数与算力照实报告，等更新不冒充等 FLOP。
4. **先固定协议，再训练。** 最多两次首轮训练，各 50000 更新 / 3 小时，计入剩余一个方法名额与训练余量。不得从 DEV 或中间 checkpoint 选优；仍按原完整分布、源保真、REAL 控制、数值与重放要求验收。若不能给出上述固定算子和可检验假设，就先完成设计，不消耗最后的方法名额进行架构试扫。

这里给出的是下一方法的具体设计约束，尚未指定或登记一套完整数学算子、网络及训练配置，不能记成 R48 已准备完成或已经启动。R47 的“统计作业完成”也不等于模型目标完成。R35/R36 的已关闭固定配方以及 R42–R46 家族的负结果均保持封存，不以本计划重开小参数搜索。

后续冻结验证顺序保持为：原 A–C 共同通过 → 一次冻结 → 原 D 效用与 E FULL/GAP → 完整 A–F 和实际交付回执。当前没有通过联合验收的新候选，不能跳过这些研究问题。
