# R66 等成本小试：独立静态方案评审

结论：主助手最新的“全量固定30步，再匹配实测墙钟”的方案可执行，足够回答一个有限问题：**从同一R65第500步模型、Adam和随机流状态出发，哪条原路线在约150秒内更改善共同TRAIN探针？** 它不能证明从原初始化到50,000步的总体收益，不能证明原A–F通过，也不能支持直接恢复约70小时长跑。

本评审只读取指定源码、R64报告和成本证据JSON；没有读取科学数组、检查点内部或权重，没有运行网络、SSH、Git或其他代理。当前R65暂停状态及CUDA速度由主助手提供，本评审没有独立核验远端。

## 可比性

- 两臂必须深复制同一已保存第500步检查点中的模型、Adam moments/step、七条原PCG64状态和CPU/CUDA RNG状态。fullD还恢复第八条full_SOURCE_epsilon流；mini不使用它，不补造相同数量的额外噪声抽样。训练随机流与探针流完全分开；先做baseline探针也不能推进训练流。
- 原R63源码127–144保持原每区32个SOURCE/REAL reference及64个REAL identity、每次出现独立噪声和原九损失。当前R65源码551–569保持同样的七流/C抽样，同时另取6593父噪声；596–598和644–647分别计算完整五D与原四C。两臂只改变已声明的路线，保留全部父人口、区域质量、冻结统计、网络、投影、clip5、Adam和损失权重。
- 两臂的原学习率都按更新编号变化：R63源码24–28/138–139，R65源码106–110/571–573。等墙钟下mini更新更多，其LR轨迹和Adam步数也不同。主助手选择保留各自step500+n日程是合理的**原路线包等成本比较**；报告不能把差异单独归因于fullD梯度估计器，也不能称为控制了LR轨迹的消融。
- 固定TRAIN评价父人口为全部6593 SOURCE和21047 REAL，保留支持外父事件。三模型共用同一8组新噪声/方向，D取完整五项，C取事前冻结的原384行微批及其原参考行/权重。C重复父出现应保留独立 occurrence 噪声；不能把fullD每父一份噪声误当作C每次出现的噪声。每模型同处理REAL全21047一次，三模型共用该控制噪声/方向。探针只评价，不更新模型，不挑选终点。

## 完整步与墙钟停止

1. fullD终点事前固定为30个完整更新。开始计时前CUDA同步；T包含抽样、噪声构造、完整D缓存/目标/VJP、原C、CPU累计、裁剪、Adam及必要计数；第30步完成后CUDA同步再读T。若180秒内不能完成这30步，本次比较无效，不把较早权重改称预定终点。
2. mini重新恢复同一起点，按同一计时边界运行，到第一个完整更新耗时达到T时停止。只允许这个整步带来的超时；要求`abs(Tmini-T) <= max(0.5秒, 0.01*T)`，否则记为`INVALID_COST_MATCH`。不做中间质量评估，不据结果延长任何臂。
3. 外部600秒硬限覆盖worker启动、人工小fixture、加载、baseline、两臂训练、全部探针和落盘。完整更新只在Adam和必要计数提交后承认；超时中断的半步不计入端点。硬限可以中断工作，但中断产物只能标为不完整，不能作为阳性比较。
4. 报告两臂完整步数、T、Tmini、计时范围、LR首末值、实际父曝光和总worker墙钟。原第500步检查点只读；pilot的Adam、流、日志和权重只写R66独立目录，不能覆盖或续写R65。

成本JSON第20–33行给出的0.103秒/mini步与5.091秒/fullD步来自不同历史测量，不能视为受控性能证据。它们只说明30个fullD步约153秒、同成本mini可能约1,480步；本次实测T和步数才是有效成本。

## 600秒是否够

静态判断为**可能够，尚未证明**。计划至少包含24次完整SOURCE探针前向、24次完整五D/固定C评价，以及3次全REAL控制前向；这不是“只多算几个标量”。仅模型前向人口就有`24*6593 + 3*21047 = 221373`行，另有C微批，排序/PSD/噪声及控制指标成本还要计入。

建议先完成baseline全部8组及REAL控制并计时E0，用它保守预留另两模型同口径评价成本；同时保留最多约360秒两臂训练和不少于20秒同步/落盘余量。若`当前已耗时 + 两臂所需预算 + 2*保守E0 + 20秒 > 600秒`，直接结束为`INCONCLUSIVE_BUDGET`。这里的保守E0需要覆盖全部计划指标，不能只取网络前向耗时。

预算不足时不临时缩父人口、删失败区域、减少8组探针、删same-treated-REAL或加时，然后仍宣告阳性。可以保存已完成描述，但主判定必须保持结果不足。保留暂停R65的GPU/RSS也属于服务器总资源占用；pilot监护需把它计入原GPU10GiB/RSS48GiB上限。

## 最小主判定与停止规则

记第j组共同九项原权重和为`L_B,j`、`L_F,j`、`L_M,j`，分别对应第500步baseline、fullD30步和等时mini。推荐只设一个主质量判定：

`mean(L_F) <= 0.90*mean(L_M)`，且`mean(L_F) <= 0.90*mean(L_B)`；同时至少6/8组满足`L_F,j < L_M,j`。

10%是这次小试的延续决策幅度，不是原A–F阈值。共同九项是统一评价器，不得拿各臂自身训练日志loss作主比较。8组配对bootstrap只描述这三个固定模型、固定TRAIN人口下噪声/方向Monte Carlo波动；它不是独立训练重复、独立采集验证或一般化置信区间。

“无实质退化”必须在运行前写成数字，避免结果出来后解释。一个简洁可执行的建议是：

- 对五D、四C、总体/每区PSD W1、已声明噪声指标及同处理REAL的非负误差，令B/M/F为8组均值（REAL控制为单次描述），要求`F <= min(B,M) + 0.05*max(B,M) + 原数值容差`。
- 对总体及事前列明的区域源PSD秩关联，要求`rho_F >= max(rho_B,rho_M)-0.02`；对Q3/Q4 h==1谷概率，要求`p_F <= min(p_B,p_M)+0.01`（1个百分点）。报告raw SOURCE参照和三模型值。小样本/退化区域若秩无法定义，标unknown，不能把unknown当作通过。
- finite、精确电荷、ADC范围和已冻结的内部约束使用原数值门；任何硬门失败立即停止。边界/支持外和投影活动保留描述，并对事前声明的边界伤害指标使用同一误差容忍规则。不能靠删除人口或修改区域质量换得改善。

这些容忍量只是本次保守延续门；原A–F及R65原50,000步端点全部保持。主助手可在登记前把“噪声/边界伤害指标”缩成已有固定清单，不应在看到结果后增删。

最终只允许三种政策结果：

| 结果 | 后续动作 |
| --- | --- |
| 主判定通过、预声明伤害门通过、成本/资源/数据边界完整 | 只允许另一次事前有成本上限的确认小试；保持长跑暂停 |
| 主判定未通过或出现实质退化 | 不恢复昂贵R65；该阴性只否定本共享起点的短程等成本支持，不证明方法一般无效 |
| 超时、成本不匹配、指标/人口/探针不完整、数值失败 | 结果不足或无效，不恢复长跑；不自动追加计算 |

R64报告第7行明确排除了四C且未训练；第20/29/47行只是冻结参照下梯度误差及有限样本分解。它不能代替这次等成本质量判断。R65成本证据JSON第35–39行也已明确：人工等价、短期训练日志和R64梯度结论都没有证明fullD长跑的质量收益。
