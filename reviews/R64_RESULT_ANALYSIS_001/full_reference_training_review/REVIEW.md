R64 后续完整经验分布 D 训练的静态技术审查

现有证据不足以否定“每次更新重新收集全部 SOURCE 父事件端点、完整 D、完整参数 VJP，加一项原 C 微批”这条路径；也不足以证明它会通过原 A–F。R64 足以反对直接把 B128 当成更好的训练梯度：在冻结 R63 末点、固定每父噪声和固定方向库下，参数 total_D 的配对平方误差 B−A 为 +206.36235254，1000 次配对 bootstrap 的 95% 区间为 [99.05100095, 343.48602558]。A/B 相对 MSE 为 2.299832/3.675589，平均 cosine 为 0.008472/0.133803；cosine 的改善没有抵消平方误差恶化。总梯度均值偏离平方从 202.122264 降至 123.189605，而经验离散度从 142.850528 升至 428.145540；PSD 的经验离散度从 137.923798 升至 411.765751。这里的均值偏离和离散度是 32 组有限诊断结果，不是总体偏差和方差估计。

本审查按 root 后续消息，把当前候选限定为完整 D + **一项**原 C 微批：原初始化、原 Adam/LR、50000 次唯一更新、原 64 行 SOURCE 重放、无 REAL 特征缓存；调用原 DistributionLoss 后只取四项 C，原小批 D 计算后弃用。root 随后明确拟议数值顺序为 joint scalar D → 单个 total G_Y → 每 64 行一次 VJP → float64 CPU 累加 → 加原 C → 一次 cast/clip/Adam，并说明 R65 尚未登记或启动。本文未打开该拟议协议，以上状态来自 root 消息。此前“四项 C 微批求平均”与有概率校正的抽样 VJP 仅保留为技术对照，未由本审查选择、登记或执行。本文只读取封存 JSON 与源代码，没有打开波形、权重、DEV/EVAL/CAL 或进行新科学计算。

R64 的参考 F 是一个诊断比较对象，不是已证最优训练目标。它只在一个训练末点、一个每父噪声场、一个方向库上比较五项 D，四项 C、Adam、梯度裁剪及参数更新均未参与。B128 结果不能外推成“批量继续增大会单调变好/变坏”，也不能直接预测从原初始化开始的完整 D 轨迹。R60 的阴性冲突结论保持；SOURCE 支持外父事件及原质量全部保留。R64 的电荷下界是带实际表示误差的名义电压贡献下界，不能证明归一化形状、切片、时序项或原 A–F 不可达。

令第 t 次更新的原参数为 θ，全部原 SOURCE 父事件为 x_i。给每父新抽一次 ε_i^D，并在本次收集与重放中固定。令 Y_i = P(raw_θ(x_i, ε_i^D)) 为原 direct endpoint 的投影后、ADC 前输出，R 为全部原始 REAL 的 canonical_REAL 表示，Ω_t 为本次方向库。完整经验目标为 D_t = D(Y, R; Ω_t)。令 G_i 为原 ADC straight-through、稳定排序 tie 分支及五项 D 约定得到的 ∂D_t/∂Y_i，J_i = ∂Y_i/∂θ，则完整参数链为 g_D = Σ_i J_iᵀG_i。这里的“精确”指完整有限经验质量和指定 autograd/STE 分支，不是量化损失的唯一经典梯度、无限噪声分布梯度或总体最优方向。

**噪声与目标的变化。** 每父新噪声意味着每次更新的 6593 个原父事件各出现一次；下一次更新重抽。原 R63 则每区域有放回抽 32 个 SOURCE 槽位，同一父事件若重复出现，每次出现也有独立 ε。二者的经验波形联合分布不同。W1、坐标 RMS、排序和平方等非线性使“对这些随机经验目标取期望”一般不同于“对噪声平均后的总体分布计算损失”，也不同于旧 D32 的期望。因此，不能把完整 D 描述成原随机目标的纯方差降低。新 D 流必须与原 C 流分开声明，不能推进原 source_epsilon 流来生成全部父噪声。若后续抽样 VJP，抽到的父事件必须重用本次完整收集的 ε_i^D；另抽 ε 会把 G_i 与另一个 Jacobian 拼接，失去下面的条件无偏恒等式。

**一项原 C 微批是更少的额外改动，但总噪声仍改变。** C 的 320 个 SOURCE 槽位与 64 个 REAL identity 槽位保持原索引、每次出现噪声、拼接顺序和一次 384 行 endpoint 调用。按原代码每次更新仍消耗 REAL_reference_rows、四个 full-window 方向矩阵及 temporal 方向，即使旧 D 最终被丢弃；将同一次原方向抽样传入完整 D，不额外推进方向流。保留所有原流的字节链、末状态和 C 曝光计数；新增 D 的全父噪声与曝光另记。C 的输入流和公式可以保持一致，实际 C 值/梯度会随新 θ 轨迹改变。旧 D 与 C 共用同一组 SOURCE 槽位/噪声，新 D 与 C 分流后 D–C 协方差改变；一 C 版本避免额外做四 C 平均，但不能声称总更新方差、Adam 状态或裁剪影响保持原样。

四项 C 必须由原函数的 pieces 原样相加，外权重仍为一。source_order 使用原非零 source-PSD 差的成对质量分母，并仅在分子保留原区间可辨对；不得改成只按可辨对重新归一化。source_valley 保留原 Q3/Q4 h=1 比例、原 SOURCE valley 占比和原 delta/smoothing。REAL_identity 比较 canonical 输出与 canonical_REAL 输入，保留对应原区域 V480 scale。box_correction 使用 (output−raw)²，同时包含投影后 output 与投影前 raw 的梯度路径，以及原 SOURCE mS_r/32 与 REAL identity 平均、0.5 混合及 0.5² 尺度。它不能由仅有 G_Y 的完整 D 缓存替代，也不能 detach raw。原 DistributionLoss 的 total/旧 D pieces 不得再次反传，否则完整 D 会与旧小批 D 重复计入。

**完整 VJP 的实现契约。** 本次全部端点收集、G_Y 计算、所有重放和 C 计算完成之前，θ、优化器状态及影响前向的状态均不更新。使用原训练模式、零 dropout attention、禁用 MHA 快路径、原 deterministic/TF32/cuDNN 设置与所有原 dtype；按原父顺序，以 64 行及末尾 1 行重放，不能把选中父事件重新打包成任意 batch。R64 已逐 chunk 检查 projected endpoint bitwise、canonical codes exact 和 Box free mask exact。新实现仍需核查自身的同图与两遍链式路径；端点相同本身不替代参数梯度核验。

G_Y 已含所有全局/条件经验质量、mS 外权重、视图/坐标/方向平均、PSD 0.01 尺度及 ADC STE。它只注入投影后 ADC 前 output 一次，由原 endpoint 图再经过 Box backward 一次；不能注入 raw、重复跑 STE/Box，或再除父事件数、chunk 数、五项数。全局 SOURCE 质量为 1/6593、REAL 为 1/21047；条件质量各自归一，full_window/RMS/temporal 的原 mS 权重、PSD 七区域等权平均和原 noise 尺度保持不变。全父 loss 的排序仍看到整条经验分布；按特征列分块可沿用，按父行拆开算 W1 再平均会改变 D。

R64 的 full 参数参考实际为五项分别得到 G_Y，再各自对每个 64 行 chunk 做 VJP，按原 chunk 顺序用 float64 CPU 累加各分量。root 拟议的 joint scalar D → 单个 G_Y → 一次 VJP 路径在实数链式法则下等价，但特征链和 float32 网络反向中的合并/舍入不保证与五项分开路径 bitwise 一致；连“分别得到 G_Y 再相加”也不能自动替代 joint scalar D 的实际反向顺序。需要人工同图/两遍检查覆盖 root 明确选定的 joint scalar 路径、f64 累加、加 C 和一次写回顺序；原 R64 收据不验证这一新聚合顺序，也不应据它声称两条数值梯度 bitwise 相同。每次更新 zero_grad 一次，合并 g_D 与一 C 梯度后才按原阈值 5 裁剪一次、执行 Adam 一次、推进原学习率一次。对各 chunk 或各分量分别裁剪/更新会改变方法。

**抽样 VJP 的必要条件，仅供未选对照。** 条件在本次 θ、全部 ε_i^D、Y、R、Ω_t 和完整 G_Y 上，记 t_i = J_iᵀG_i。对无放回或 Bernoulli 设计，若 I_i 表示是否纳入、π_i = P(I_i=1 | 本次完整信息) 已知且对可能非零 t_i 为正，则 ĝ = Σ_i I_i t_i/π_i，条件期望为 Σ_i t_i。设计可以依赖已固定的本次信息，但必须使用真实的条件包含概率，概率系数停止梯度；不能事后按实际选中数自归一。对 K 次有放回、每次概率 p_i 的抽样，用 ĝ = (1/K)Σ_k t_{I_k}/p_{I_k}，而不是把每次抽样概率与“至少出现一次”的包含概率混用。按区域均匀有放回抽 K_r 次时，相应系数是 N_r/K_r；G_i 中已有该区域目标质量，不能再乘 mS_r。重复抽中父事件的贡献需按实际次数累加，且不重抽噪声。零概率只可用于已严格证明其本次贡献为零的行，不能据估计小梯度删除父事件。

这些恒等式只保证选定有限分支的条件梯度均值；它们不保证低方差、经裁剪/Adam 后的无偏更新或 A–F。先对子集重算 D/G_Y 不是上述方法。抽样仍需要本次完整 SOURCE 前向、完整 REAL 参考与全 D 的 G_Y，最多减少后续参数重放/VJP。为维持原 64 行数值上下文，常需重放命中的完整原 chunk，仅将未选行的注入置零；可能削弱预期节省。当前选定完整 VJP 路线无需引入这些概率设计或新增抽样流。

**共同成本与现有资源证据。** 每次更新至少有全部 SOURCE 端点收集、完整 SOURCE 重放、全部 REAL 的 canonical/特征与完整经验排序、加原 384 行 C 前向/反传及被弃用的旧 D 计算。无 REAL 特征缓存时，不能用“只做 6593 个 SOURCE”估计全部费用；完整 D 的多项特征图、排序索引/反向存储、CPU/GPU 传输、参数累计、C 图与 Adam 状态都会影响峰值。R64 的完整诊断总耗时 1148.381778 秒，完成 245209 行/3865 次神经前向、33800 次分量 VJP、161 次端点目标、33 次 SOURCE 重放；CUDA allocated/reserved 峰值为 1398710272/1568669696 字节，监督器测得实际 worker RSS 峰值 4645408768 字节、GPU 进程峰值 1862270976 字节。监督器另记录两次实际 PID RSS 查询不可用事件，原因未知。这些是含人工检查、几何、REAL control、32 配对诊断和输出的整次运行数据，不能除以某个计数就声称新单次更新或 50000 次训练用时；R64 也没有训练用的 C 图与 Adam 更新，不能据此保证新训练峰值。

保留一 C 原调用、完整质量、原噪声流、正确 G_Y 注入、明确数值聚合与唯一更新之后，这条路线在代码和链式法则上是可具体实现的候选。它针对 R64 暴露的有限经验 D 估计差异，但新噪声场下的梯度变化、D–C 联合作用、原初始化附近的行为、长程优化和最终 A–F 都尚未被 R64 检验。将 W1 改为平滑/energy 目标会另行改变距离、梯度或统计含义，需新的问题依据，不能视为此次完整经验积分的实现替换。本文没有执行该替换或任何扫描。
