# 验收目标的兼容性说明：电荷人口与共同处理

本说明基于已封存的 R43 统计、当前 PROJECT_ACCEPTANCE v1 科学条款和 R45 的既定推理定义。它是根的分析，不是新拟合、独立验证或修改验收线；R45 继续完成已登记的数值门和允许的评价。

R43 保存的全部 2000 条 SOURCE_INPUT 相对 2000 条 REAL，Qtotal 的经验 KS=0.2685、W1=1842.558452 mV ns。逐事件保留电荷的 R43 输出相应为 KS=0.2685、W1=1842.548338；同规模 TRAIN_REFERENCE 相对 REAL 则为 KS=0.019、W1=126.029329。这些是封存结果，不是重新计算。源和观测样本的电荷人口确实不同，不能把该差异全部归为响应模型训练不足。

对同一电荷定义，若每一源事件的输出电荷严格等于输入电荷，且事件/权重保持，则输出的经验电荷分布也保持。完整的联合 Q–PSD 分布若相等，其 Q 边缘必须相等。因此当前两个经验人口无法在“严格保留每事件 Q”条件下获得完全相同的联合分布。R45 的实际要求为 preADC 相对误差不超过 1e-5，并另外执行 ADC 舍入，不能据此声称整个推理严格逐位保留 Q，也不能用舍入掩盖原有人口差距。

对于等类别权重、允许两个判别方向、在同一完整样本上选择最佳 Q 阈值的描述性分类器，最大平衡准确率恰为 (1+KS)/2。将上述已保存 SOURCE KS 代入得到 0.63425。这个数使用全部样本选择阈值，既不是当前固定 HGB 的留出 BA，也没有新的分组置信区间；它不能证明 PROJECT_ACCEPTANCE 中固定 HGB 区间上界 0.60 的目标必然失败。但它给出了一个明确的人口混杂来源，不能把提高训练步数作为消除它的保证。

另一个需要区分的问题是“相同变换同时把源和已实测输入变成同一分布”。在理想确定性且可逆的共同映射 T 下，若 T#P=Q 且 T#R=Q，则施加逆映射可得 P=R。这里 # 表示分布的推前。这个逻辑只针对严格等分布、相同可逆映射及其相同输入空间。当前初始噪声、归一化、电荷分区、有限步求解与 ADC 的整体管线不能未经证明就当作该理想映射；当前固定视图和有限 HGB 也只要求近似、有限能力的可分性。因此这不是对当前方法或所有 sim2real 方法的不可能性证明。

共同处理 REAL 是有价值的失真控制，但其角色和“源条件下的真实探测器响应”需要分别解释。所有源总体、同电荷条件结果、同处理 REAL 与 RAW REAL–REAL 都继续报告。不得根据这段分析改源权重、删支持外 417 条、隐藏总体失败、降低 A–C 门槛或把条件成功写成总体成功。如后续证据表明现有目标存在实质冲突，应先把冲突和候选目标写清，再决定新的研究范围；当前目标不变。
