# R70：实测电荷目标下的公共条件 Q-head 静态建议

结论：新目标允许显式改变模拟输入电荷，应该把原“保存输入 Q”拆成“学习目标 Q*”和“在 Q* 上生成完整条件波形”。只建议一个下一入口：依赖共同归一化 480 点波形的公共条件 Q-head，随后仍使用电荷一致的完整波形残差及 Box/ADC。先检验这个小头能否兼容 SOURCE 电荷目标与同处理 REAL 保持，再决定条件波形学习；没有理由立即启动长训。训练架构、损失系数、步数、预算和判定门都待根后续单独预登记。本轮只做静态准备；根已确认 goal 为 paused，不启动科学作业，不改判旧结果。

## 当前约束实际锁住了什么

R63/R65 的 `source_flow_core.py:7-10` 定义 q(x)=sum(x[100:400])-3sum(x[0:100])，它是 480 点保存窗的电荷代理。`displacement:57-62` 把网络位移投到 q 的零空间；`endpoint:64-67` 再 `bounded_charge(raw,q_input)`；`solve:73-84` 同样将原 q 用于 bin、连续条件和最终投影/1e-5 数值检查。因此原模型的形状网络不能改变电荷谱，除去量化/舍入。新用户目标直接改变的是这个科学约束，Box 的有限/范围约束、规范 ADC 和相对“声明目标 Q*”的数值一致性仍应保持。

原 `BoxChargeProjection.backward:32-37` 已返回对 q 参数的梯度 gq，因而技术上支持可学习 Q*。但只把最后一次调用改成 `bounded_charge(raw,Q*)` 不够：原 raw 仍位于输入 Q，投影会被迫承担整个电荷改变，同时网络、噪声和条件统计仍处在旧 bin；这会混淆校准与投影引入的形状失真。

## 为什么不是重复 R2/R3B 自由幅度

R2 已经用学习 gain、能量指数与随机乘性响应改变电荷（`model.py:57-62`）；报告记录 gain1.19485/指数0.83857，电荷 W1 明显改善，完整形状 C2ST BA 仍0.992，低电荷覆盖和前沿不足（`REPORT.md:15,29,40,48-55`）。R3B 保留自由电荷（`model.py:76-81`），加条件 PSD CDF/占比目标，中间共同六区峰位与宽度改善，但完整 BA0.996，高电荷尾覆盖仍不足，最低区偏移、最高区未收敛（`REPORT.md:29,35-59,76-86`）。这些是旧封存人口/开发评价的结果，不是当前新方法的试验。

两份旧模型文档明确条件来自 G4 清洁期望，非 REAL 输入（`model.py:9-14`）；所读报告/接口没有提供可核验的公共 REAL 路径及其分布不变证据。其低维正指数形状族、局部时基和条件 PSD 改善也没有建立完整联合波形正确性。不能用“放开 Q 会成功”、FoM 接近、峰宽改善或旧 gain 作为下一方法的充分依据。旧 gain/指数还依赖源谱与无配对目标，不是独立器件/能量标定。

## 唯一候选入口：公共条件电荷头 + Q* 条件波形

对两域相同的波形输入 x 和预处理，取 Q0=q(x)>0，beta=mean(x[0:100])，u=(x-beta)/Q0。所有 480 点进入同一小头；任何标准化只由合法 TRAIN 拟合并对两域一致。不能输入 SOURCE/REAL 标志、父 ID、文件来源、REAL 专用开关或仅 SOURCE 才有的 G4 真条件。沉积/组成元数据保留作来源与趋势审计，不为 REAL 杜撰对应真值。

一个可实现的初始参数化是两个公共输出 a_phi(u)、b_phi(u)，末层零初始化，Qref 为固定 TRAIN 标尺：

    Q* = Qref * exp(a_phi(u)) * (Q0/Qref) ** exp(b_phi(u)).

零初始化为恒等。固定 u 时对 Q0 单调，保留该条件下的幅度趋势；跨不同 u 不要求一个全局一维单调 T。单一确定单调 T(Q) 若保持连续 REAL 电荷分布，通常必须在其支持上为恒等，不能同时改变不同的 SOURCE 谱。公共条件头使用波形条件绕开这个一维结构限制，但不保证存在兼容解，也不证明学得的改变具有物理校准意义。小头即使利用真实波形差异，也必须接受完整同处理 REAL 约束，不能以识别域后绕过处理代替它。

将 Q* 真正接入现有波形端点，建议显式电荷坐标 lifting：从冻结、合法 REAL TRAIN 的条件均值取 m_b=mu_b/q(mu_b)，使 q(m_b)=1；按 Q* 取 b*，构造

    x* = x + (Q* - Q0) * m_b*,
    q(x*) = Q*,
    n* = 原零电荷 innovation(x*, epsilon, ...)，两域共同 completion 规则，
    delta* = Q* * P_m[scale_b* * F_theta(noisy*, b*, guide*, logQ_condition*)],
    raw* = x* + n* + delta*,  out* = BoxChargeProjection(raw*, Q*),
    saved* = 共同 canonical ADC(out*).

这里 P_m(z)=z-m_b*q(z)。它保持完整原波形残差而显式移动电荷坐标，避免整条 x 乘增益把基线随机噪声一起放大。m 的支持/单位电荷必须核验；lifting 也可能改变 PSD/前沿并触发范围投影，所以必须报告其自身变化，不能称为无害。q0 和 q* 必须有限，现有正 Q 接口与 |Q*|<=300 可行性不满足时整候选失败，不裁掉事件、把 Q 压进目标区或用 clamp 隐藏不可行。后续联合学习若经过原 NumPy bin/noise 包装，不能默认为保留了 Q-head 梯度；必须显式核对可微连续条件、分段 bin 语义及 Box 的 gq。

SOURCE 与 REAL 必须调用同一个 `transform(x,epsilon)`，包括 Q-head、lifting、噪声 completion、形状网络、Box 和 ADC，参数/分支规则相同。第一兼容性阶段可把形状残差置零/冻结，只拟合小头；不继承已失败的 R63 权重后宣称 REAL 保持。低成本来自只更新标量头、无需回放全部大网络 VJP；它只回答电荷坐标兼容性，完整条件波形尚未学习/通过。随后一次完整共同波形评价必须核对 REAL 的 Q、PSD、基线/ACF、峰形与边界，REAL 小头电荷恒等损失不能替代实际输出分布检查。若公共头无法改善 SOURCE 谱且保持 REAL，关闭这一参数化；不添加 REAL bypass。

## 必须显式迁移的分区和人口语义

保留每个原父 ID、顺序、原 Q0 和原事件权重。每条记录同时保存原输入 bin b0、声明 Q* 与 b*、实际 preADC Q、ADC 后 Q 与 b_ADC、lifting/Box 修正、随机流/模型/统计哈希。新旧绑定与科学目标迁移须版本化；新数值门检查 Q* 一致性，另报 Q*-Q0，不能覆盖原 q 字段或把旧失败改判为通过。

旧原输入 bin 仍可作为抽样分层/来源审计；若这样抽样，必须按原每父权重还原总体。当前旧损失用固定 SOURCE bin 槽位及旧 region masses（`R61_distribution_loss.py:57-63,81-97`），不能直接把它当新 p(waveform|Q*) 的分区。新的条件目标与评价按输出共同 canonical Q 及冻结 REAL 边界归区，输出区成员与条件分母需新版本声明；原 bin→Q* bin→ADC bin 的迁移表单列，保留范围外与边界跨越父事件。global 父权重不因迁移、稀缺区补样或更漂亮的条件曲线而改变。任何原源顺序/valley 条件的沿用或重定义也须明说，不能悄悄重新分箱后将旧门算作原样保留。

## 电荷谱与稀缺区补样是两个问题

目标应区分 p_REAL(Q) 和条件 p(waveform|Q,来源趋势)。前者的有限 TRAIN 经验质量由完整 REAL 人口给出；后者在稀缺区可以由模拟趋势提供可检验的结构先验或插值候选，不能仅凭前者匹配推出后者正确。稀缺区增加生成次数是条件设计样本，不会自动增加该区真实发生概率或独立父样本量；它与按 p_REAL(Q) 输出总体应分别声明。

缺口掩码至少记录每区 REAL/SOURCE 有效支持、稀缺/足够/零观测、边界外、原参考未定义和插值/外推状态。零 REAL 观测只能说明经验支持缺失，不能断言真实概率为零，更不能以模拟任意补入概率质量并称已知。零覆盖条件波形只可标记“模拟外推、缺少实測约束”，不进入“已验证条件相似”集合；不强拟合双峰、补造标签或将 undefined 改成通过。原 G4 还缺失未存零沉积历史，真实入射谱/触发效率未知（R68 来源报告:9,25），不能从既有波形恢复这些率。

所有拟合/新常数/检查只用当前合法 TRAIN；旧 R2/R3B 的 DEV 结果仅用于避免重复失败。电荷分位数或公共头拟合最多称“该源/目标人口下的统计电荷迁移”，不是 MeV/MeVee 标定、淬灭测量或唯一探测器传递函数。真正物理标定和零覆盖概率质量需要独立标定/采集/曝光信息，当前证据没有提供。

本报告只交这一条可实现入口。公共 Q-head 的结构、损失、有限预算及完整条件/REAL 判定尚未冻结；没有训练、推理、新探针或数组解码。来源 SHA 与本地静态资源回执随报告保存，根决定是否另行预登记计算。
