# R65 完整有限经验分布：剩余误差与两个未执行假设

完整 D 去掉的是给定本步父事件、噪声和方向后，对 D 再做父事件抽样、微批损失平均和参数 VJP 抽样的误差。每父一份新噪声仍只给出一个随机经验 law；完整求值不把它变成条件噪声积分、总体分布或可识别的物理响应。本备忘支持保持正在运行的 R65 冻结定义，并仅为其结束后的独立诊断留下可检验假设。

范围绑定于 R65 协议 SHA256 `324b8e925cbc1b65578b3e36614693ae6cfb5561d0b3e379293ceab7aa4e256b`、driver `54834b0fd73ee08a420096e791be6038c2193acfb22c91c81563e059b64c67f3` 和根静态审查 `e0a4b101886f5cb10b205364fe8414ca2db1fa211cbb058de7d4113f85ba24f5`。这是一份文本与公式分析，没有运行下列诊断，没有读取新的波形数组、权重、DEV/EVAL/CAL，也不根据训练日志选模型。读取的启动审查仅作来源元数据，未用于科学结论。

已经比对 R63 等待期文献、R64 literature_followup、full_reference_implementation_review 和 full_reference_training_review，详见 INPUT_BINDING.json。这里不重写已有的整数 CDF、两遍 VJP 和采样参数 VJP 推导；新增重点是噪声混合、有限原子质量和 D/C 联合随机性。R64 固定噪声的结果、R60 的已关闭负结论及原 A–F 均保持原义。

**先区分三个对象。** 令 θ 固定，Ω 是本步两套方向，ν_M 是 21047 个 canonical raw REAL 父事件的完整参考。对每个 SOURCE 父事件 i，ε_i 按原默认 float64 正态抽样再转 float32，经原 innovation、网络、Box 和 canonical ADC 得到 z_i(θ,ε_i)。μ_ε 是 6593 个输出的等质量全局 law，以及十个区域各自的完整等质量 law。D_Ω 以原常数和原区域权重作用于这些 law；所有尺度与权重保持固定。

\[
L_1(\theta)=\mathbb E_{\varepsilon,\Omega}D_\Omega(\mu_\varepsilon^\theta,\nu_M),\qquad
\bar\mu^\theta=\mathbb E_\varepsilon\mu_\varepsilon^\theta,\qquad
L_{\rm mix}(\theta)=\mathbb E_\Omega D_\Omega(\bar\mu^\theta,\nu_M).
\]

R65 每步完整计算第一式内的一次 D。即使固定 θ 重复无限多步，平均损失也指向 L₁，而非一般意义下的 Lmix。实际训练中 θ 还在变化，跨步平均甚至不是同一 θ 的 Monte Carlo 估计。Rainforth 等的嵌套 Monte Carlo 分析明确区分固定内层样本时的极限与原嵌套目标；其定理 1 另要求 Lipschitz 连续和 L² 条件。本项目是有限父事件的分层经验测度，不直接套用该文的收敛率。[原论文，§3、定理 1](https://proceedings.mlr.press/v80/rainforth18a/rainforth18a.pdf)

**本项目可直接推导的值域关系。** 对固定方向、固定变换后的特征和固定 REAL law，一维 W1 对 SOURCE 测度是凸的，因为它等于 CDF 差绝对值的积分。坐标 W1 向量非负；其 RMS 是在非负正交域单调的凸范数。其余 D 项是非负权重的坐标或投影 W1 和。因此，原五项 D 连同 coordinate_RMS 均满足

\[
D_\Omega\!\left(\frac1K\sum_{k=1}^{K}\mu_{\varepsilon_k},\nu_M\right)
\ \leq\ \frac1K\sum_{k=1}^{K}D_\Omega(\mu_{\varepsilon_k},\nu_M),
\qquad L_{\rm mix}\leq L_1
\]

后一个期望不等式以相关期望存在为前提。这是此处依据原 D 定义给出的推导，不是论文对 R65 的实验结论。RMS 处的理由是先逐坐标用 W1 的凸性，再用范数的单调性与三角不等式；没有把 RMS 错当成线性平均。每区域池化后，每个噪声出现的质量为 1/(K·N_S,r)，外层 SOURCE 区域质量不变。ADC 可先生成固定特征值，因此这个值域不等式不要求 ADC 可导。

标量反例足以说明等号并非恒成立：参考 ν=(δ₋₁+δ₊₁)/2，随机单点 μ 以各半概率取 δ₋₁ 或 δ₊₁；每次 W1 都为 1，而 Eμ=ν 的 W1 为 0。这只是手工数学例子，没有执行仿真。池化不等式仅限前向五项 D 值；降低这个损失不证明 ADC STE 参数梯度的范数、误差或方向更好，也不证明 clip/Adam 更稳定、物理响应更好或 A–F 更容易通过；它首先改变了所估计的随机目标。

| 层次 | 完整 D 能去掉的部分 | 仍需保留的边界 |
|---|---|---|
| 本步 D 的父事件 law | 不再对 SOURCE/REAL 父事件抽样后重估 W1；不再平均多个微批 D 代替完整 D | 每父仍只有一次噪声；有限训练父事件与总体的差别仍在 |
| 本步反传 | 对完整 endpoint GY 做所有父事件的参数 VJP，无参数 VJP 抽样 | 浮点归约、ties、Box 与 ADC 的选定反传规则仍在；静态/人工检查只验证实现一致性 |
| 方向 | 每步使用原两套方向，且各完整 law 共享实际本步方向 | 有限方向的 Monte Carlo 波动仍在；不能把每步有限切片值当成全部方向积分 |
| C 与优化器 | 每步原 320 SOURCE + 64 REAL identity 出现，原四项 C 加入同一个梯度 | C 的父事件/每次出现噪声仍是随机的；D/C 联合噪声律发生改变，clip/Adam 是非线性的 |
| 可解释性 | 完整经验 law 的值和所选算法梯度更明确 | 分布匹配、条件宽度、父事件保持和独立采集泛化仍需原证据分别验证 |

Fatras 等定理 29–30 针对其指定 OT 核：参数化样本映射需 C¹，换序还需有限矩及附加可积性；结论是相应期望目标的广义导数关系。R65 的硬 ADC forward 与指定 STE backward 不构成该定理已验证的实例；Box/网络的分段结构也不能未经证明就替代这些假设。因此这里使用“选定算法梯度”g̃，而不声称 g̃ 无偏估计硬量化损失的经典 ∇L₁，更不声称其为 ∇Lmix。[原论文，定理 29–30、附录 7.6](https://arxiv.org/html/2101.01792v1)

**有限人口与原子质量。** 完整读取一份训练 archive 消除了 archive 内的抽样近似，没有增加新的采集父事件。Fournier–Guillin 定理 1 从 i.i.d. 的 μ 样本及有限 q>p 阶矩出发，界定经验测度与 μ 的 Wasserstein 误差；维数、矩条件和未知常数都进入界。已有父事件是否独立、重复采集是否相关，以及学习后的 θ 是否满足相应统一泛化条件，本备忘均未核验，故不把该定理换成项目置信区间，也不直接套到固定父事件、各自不同条件噪声的分层样本。[原论文，§1.1–1.2、定理 1](https://arxiv.org/pdf/1312.2128v1)

另有一个仅依赖已登记整数计数的观察：gcd(6593,21047)=1。若两边均为等质量经验测度，在任一相同原子值上的相等质量需 a/6593=b/21047，即 21047a=6593b；互质性要求 a、b 同时为零或各自总数。因此，当 REAL 的某个全局一维特征 law 非退化时，这两个大小的经验测度不可能完全相等，其 W1 不能精确为零。这里没有读取特征来认定哪些 law 非退化，也没有计算这个正下界的大小。这个结构事实不证明实际损失有多大，也不能推出原 0.01 门不可达；原评价另有其人口，应按原定义判断。区域计数还应各自判断，不能把全局互质性推广到每个区域。

**相同平均梯度并不固定一次更新。** 固定 θ 及历史状态，记未裁剪算法梯度为 g̃_D、g̃_C。只要 D、C 各自的边缘随机律相同且一阶矩存在，改变它们的耦合不改变 E(g̃_D+g̃_C)。二阶矩却有

\[
\mathbb E[(\tilde g_D+\tilde g_C)_j^2]=
\mathbb E[\tilde g_{D,j}^2]+\mathbb E[\tilde g_{C,j}^2]+2\mathbb E[\tilde g_{D,j}\tilde g_{C,j}].
\]

联合范数 clip(g)=g·min(1,5/‖g‖) 可改变平均值；R65 的 Adam 接收的是该裁剪后梯度 h，二阶状态更新含 hⱼ²，随后还要通过开方与比值形成更新。Adam 原算法确认了这条状态依赖，以上 D/C 交叉项与耦合解释是本项目推导，不是该文对本任务的收敛保证。[Adam 原论文，Algorithm 1](https://arxiv.org/pdf/1412.6980v9)

原 R63 的 D 与 C 共享微批端点；R65 的完整 D 使用独立的新父噪声流，C 保留原抽样律。此变化已写在 R65 协议中。完整 D 与独立 C 的组合既改变了 D 的求值，也改变了联合随机性和计算/曝光量，所以不能把结果全归因于一个无偏梯度估计器。它也不撤销 R60 的负冲突证据；上述公式没有证明当前 D/C 存在有害冲突。

**可识别性没有被完整经验求值解决。** D 约束的是特征与投影的分布；它本身不提供真实父事件到响应之间的配对。source_order、source_valley、identity、Box 和架构可能缩小允许的映射集合，是否足以唯一确定物理响应仍需项目证据。Moriakov 等在纯 CycleGAN 假设下证明测度保持自同构可生成另一组精确解；这里没有反向映射或 CycleGAN 损失，不能把其命题当成 R65 不可识别性的直接证明，只用来说明“分布匹配加附加约束”仍需单独检查识别假设。[原论文，命题 2.1–2.2](https://arxiv.org/pdf/2001.09061v1)

**H1：单次噪声经验 D 与噪声池化 D 的差可被数值分辨。** 这是优先考虑的后续诊断；状态为“提出、未登记、未执行”。未来另行登记时固定唯一合规的 θ、原父事件/顺序、REAL 参考、常数与一套方向，不读取 DEV/EVAL/CAL。设 32 个独立噪声组，每组每父生成 K=4 份原抽样律的独立 ε。先以原 64 行神经分块取得各自的固定特征，再比较 A_m=四个完整 D 的平均与 B_m=四份特征出现等质量池化后的一次 D。不要平均波形、合并同父端点、改区域质量或对每个子组重新拟合特征。C 不参与这一值域诊断。

主量是 Δ_m=A_m−B_m 及其平均；同时按五项报告、记录 Δ/A 的描述性比率。32 组和 1000 次按组配对 bootstrap 在读科学结果前固定。τ_D 必须先由新的纯人工池化检查及冻结数值设置登记；该备忘不替项目选定 τ_D。通过规则：全部 Δ_m≥−τ_D，且平均 Δ 的 95% 区间下端高于 τ_D。若任一 Δ_m<−τ_D，先停下并保留机械失败；若区间不能分辨差异，则以“未分辨”结束，不改阈值或追加自适应组数。通过只说明固定状态下存在可分辨的值域差，不能据此更改 R65、激活新训练或宣布梯度/响应收益。该 bootstrap 描述的是固定 archive、θ、方向下的噪声重复性，不覆盖新父事件或独立采集误差。

**H2：保持 D、C 各自边缘律，改变其耦合可分辨地改变交叉二阶矩。** 同样是未来另行登记的固定 θ 诊断，32 组、1000 次配对 bootstrap、种子/方向和数值容差先冻结；不提交任何参数更新。每组完整生成原 C 的父事件序列及所有逐出现 ε_C，重复父的各出现噪声独立。独立臂按 R65 为每个 D 父生成 ε_D。耦合臂仅对在 C 出现的每个不同 SOURCE 父 i，把 ε_D,i 替换为该父第一次 C 出现的白噪声；其他 D 父沿用独立臂 ε_D。C 的任何数值与 REAL identity 噪声均不改。

条件于 C 的父序列，不同父的“第一次出现”索引不同；被选 ε_C 彼此独立并与其他 ε_D 独立，且抽样律相同。因此两个 D 臂各自仍具有原完整独立父噪声边缘律，C 更是逐出现保持原律。不得把同父全部 C 出现替换成同一个 ε_D，那会改变 C 的联合噪声律。该构造依赖原协议关于独立随机流的模型，并只复用白噪声，再执行原 innovation；不偷换不同噪声预处理。

固定 θ/方向，分别以完整 VJP 得到两个 g̃_D，C 参数梯度在配对两臂需逐位一致。主量为 q_m=2⟨g̃_C,g̃_D,coupled−g̃_D,independent⟩，其期望正是未裁剪总梯度平方范数期望的变化，因为 D 自身二阶矩边缘相同。通过规则：先通过人工边缘律/重复父构造检查、C 逐位一致及原 replay 检查，再要求 q 的配对 95% 区间排除预先登记的 [−τ_q,+τ_q]。否则停止为“未分辨”；区间包含零不证明所有坐标协方差、裁剪概率或后续轨迹相同。

辅助量可包括联合裁剪率、裁剪后范数和从同一份绑定 Adam 状态计算的一次影子更新差；它们仅作描述，不作为新接受门槛。没有与 θ 同步的可验证 Adam 状态时，省略 Adam 部分。q 的任一符号都不是成功标志：它只区分耦合，不把“较低范数/裁剪率”解释成物理收益。两个臂不比较完整 R63/R65 训练轨迹，不改变损失或原 A–F。

独立采集泛化与响应可识别性没有被这两项诊断覆盖，仍沿用原评估边界。当前最有证据的行动是让既定 R65 按原协议完成和接受原门槛；这份备忘没有触发新科学作业、训练调整、参数更新或验收变更。
