## 噪声算子的完整定义

对任何输入 x，以前100点的居中 sample variance（分母99）定义 `v(x)`，单位 V²，两个域使用同一个公式。对固定唯一 TRAIN 行的 v_i，取 `tau2=quantile(v_i,0.05,method='linear')`。0.05 是在本轮任何数值前固定的保守低分位，不扫描、不依 DEV 更改。若 tau2 非有限或非正，关闭本方案。

共同 colored 核 K0 按以下唯一方法构造。将每条 TRAIN 前100点减其自身均值，使用100点 `rfft(norm='ortho')`，对复系数模方按事件等权平均，得到频率 j/100（j=0..50）的51个非负谱值。以线性插值取得 k/480（k=0..240）的谱 p_k，DC 固定为0，其他不加平滑参数或事后频谱下限。对480点标准正态 epsilon：

`K0(epsilon)=irfft(sqrt(p)*rfft(epsilon,norm='ortho'),n=480,norm='ortho')`。

Q 投影会改变噪声。每个 b 必须在投影后归一化：

`kappa_b² = sum_{i=0}^{479} var100(P_b K0(e_i))`，

其中 e_i 是480维标准基，var100 用同一个居中分母99定义。这等于 `trace(C B P_b K0 K0^T P_b^T B^T C)/99`，是标准正态经线性算子后的基线期望方差；计算为确定性线性代数，无 Monte Carlo 拟合。各 kappa_b² 必须有限且>0。固定单位核 `H_b(epsilon)=P_b K0(epsilon)/kappa_b`。

- 对照：`n(x,epsilon)=sqrt(tau2)*H_b(epsilon)`。
- 主候选：`n(x,epsilon)=sqrt(max(tau2-v(x),0))*H_b(epsilon)`。

全480点初态均为 `x+n`，没有域标签、REAL 特判回退、输出替换或后验删除分量。在输入与新 epsilon 独立的假设下，候选初态的条件基线期望方差是 `max(v(x),tau2)`，对照是 `v(x)+tau2`；这不是每条实际波形方差逐值相等，也不保证准确补齐频带协方差。

此规则只提供保守随机种子。SOURCE 的低方差补至 TRAIN 低分位，剩余噪声幅度与完整响应仍需学习；REAL 低尾会受到影响。100点估计误差、平稳/加性/信号独立假设、谱插值及电荷投影均限制物理解释。必须报告这些影响和最终噪声距离；不得称物理去噪、信号/电子噪声真值分离或自动 REAL 恒等。

## 两臂共同的完整 guide 网络与训练

每个原32行批同时构造32条 SOURCE 响应轨迹和32条 REAL 身份轨迹。SOURCE 轨迹用原 source x 与 matched_target r；REAL 身份轨迹用同一批 r 作为自身输入和目标，不再引入新行，也不把 SOURCE–REAL 统计耦合称为真实逐事件配对。

对任意输入 x：`q=q(x)`、`b=b(x)`、固定完整 guide `g=(x/q-mu_b)/s_b`，臂相关初态 `a=((x+n)/q-mu_b)/s_b`。

- SOURCE 终态 `c=(r/q(r)-mu_b)/s_b`；线性路径 `y_t=(1-t)*a+t*c`，速度标签 `u=c-a`。目标单位电荷形状仍乘回原源 q，不拟合或改变源电荷人口。
- REAL 身份轨迹用 x=r 和自身 b(r)，终态 c=g，其余公式相同；速度标签是去除本轮新加创新所需的线性速度，不把输入原噪声当真值干净波形。
- 共同场 `f_theta(y,t,g,b)` 使用 R43 的32/64/128/128 U-Net、GN8、60点4头 attention、nearest upsample、两层残块与原 scalar `[t,zero16]`+8 bin embedding。唯一共同网络接口改动为输入 Conv1d 的3通道 `[当前状态y,固定完整guide g,position]`；无域标签、单独 REAL head 或逐域推理分支。末层零初始化；记录实际参数量和源码。
- 网络 float32，坐标/投影/积分 float64；预测场 `P_b(s_b*f_theta)/s_b`。损失固定 `0.5*MSE_SOURCE480+0.5*MSE_IDENTITY480`，无额外 PSD/噪声/对抗/重加权损失。报告两个分项及实际梯度，禁止按 DEV 改权重。
- 两臂同一个全新初始化，Torch seed 20261010480；不加载旧响应或优化器权重。Adam lr=2e-4、betas=(0.9,0.999)、eps=1e-8、weight_decay=0、clip=5，固定50000更新。控制先运行，再运行主候选；每臂恢复同一初态和随机流。SOURCE t、SOURCE epsilon、IDENTITY t、IDENTITY epsilon 分别由 PCG64 seeds 20261010481/482/483/484 产生，t 是 uniform(0,1,32).astype(float32)，epsilon 是 standard_normal((32,480)).astype(float32)，每步每流顺序固定。保存起止 RNG、累积流摘要及每批原流使用次数，避免保存全部大噪声矩阵。
