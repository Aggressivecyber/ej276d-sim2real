## 固定可部署转换

输入仍为原始完整480点源波形以及同一z8、white480、style8。固定R32 CONTROL_FINAL生成器给出x0，固定R33末点流给出x1，均为ADC前电压。沿用原Q分区、支持外BASE回退、CPU4、32步Heun；最终仍只有一次原14bit ADC[-.5,.5]，不先量化x0/x1再投影。

令d=float64(x1)-float64(x0)。定义唯一投影P：

```
(Pd)[0:100]   = 0
(Pd)[100:150] = d[100:150] - mean(d[100:150])
(Pd)[150:400] = d[150:400] - mean(d[150:400])
(Pd)[400:480] = d[400:480]
x_protected  = float64(x0) + Pd
```

它是普通电压欧氏范数下，到“前100点增量为零、100:150和150:400各自增量和为零”子空间的正交投影，秩378。无实测事件、域身份、DEV统计、拟合常数、额外缩放或阈值参与投影。两端点命名`INDEPENDENT_PROTECTED`与`OT_PROTECTED`，均由原完整源波形驱动并可单独部署。

原评价的baseline是前100点均值，Qtotal为扣该baseline后100:400求和乘1000，Qfast为100:150积分，PSD=1-Qfast/Qtotal。因此float64投影在舍入精度内保留BASE基线逐点、Qtotal及Qfast；这仅保护BASE已经学到的响应代理，不证明原G正确或真实电荷绝对标定。投影会保留BASE既有Q/PSD分布误差，不能将不变的统计写成进一步拟合REAL的收益。

沿用原ADC函数内部float32输入转换及量化。分别保存或明确记录float64投影结果、float32 ADC输入、最终ADC输出，报告三者Q/PSD差，不把量化后的积分写成严格相等。前100点经同ADC应与BASE逐值一致；主输出postADC的源谷比例/秩关联等仍按实际值评价。由分段均值相减可能产生的边界结构必须保留，禁止事后平滑、换窗、换投影度量或改保护区。

在本轮一次小张量检查中验证P线性、P²=P、保留与移除增量正交、两段和及baseline条件、支持外零增量、推理接口父ID顺序。实际4000主行同时报告各项最大残差（float64段和绝对残差<=1e-10 V）、ADC前float32舍入改变及后量化Q/PSD变化；不能用小张量通过代替实际数组结果。所有检查计入科学预算。

## 继续或关闭规则

分别给两份保护端点判定，不宣称OT增益。一个保护端点只有同时满足下列条件，才可保留为下一轮开发对象：

3. 相对BASE，总体/共同观察Q区PSD W1、低/高raw-width MAE、baseline RMS和ACF1 W1均不恶化>10%，零基线要求不增加。BASE原来有效的密度区2–7若新增候选支持/收敛失败，明确判定该保护配方未通过；不只报更小共同交集。
