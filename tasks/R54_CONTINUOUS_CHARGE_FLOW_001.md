# R54：连续电荷条件的单一固定消融

由主助手独立执行，无子智能体。R53 已以 A/B/C 全部失败封存并完成私有 Git 与 D 盘交付；本轮不改写负结果。长期目标仍为同一冻结方法满足原 A–F 及实际交付，不以本轮完成或局部改善替代。

R53 神经场直接接收归一化状态、归一化完整 SOURCE guide、时间和八个电荷区间编码，未直接接收连续电荷。电荷已用于外部坐标变换和初始噪声幅度，因此不能声称网络完全不含电荷信息。本轮只检验显式连续电荷能否改善区间内响应；不预先认定它是此前失败的原因，也不宣称它能修复保留的 SOURCE 与 REAL 电荷人口差异。

## 唯一改动

保留原 25 维 embedding 输入和全部参数张量形状、初值。原输入为 `[t, 16个零, 8维Qbin]`；本轮改成 `[t, h, 15个零, 8维Qbin]`，激活原第 1 列的 128 个已有权重。时间仍为单个标量，不启用傅里叶频率。

对输入原始波形定义 `q = sum(x[100:400]) − 3 sum(x[0:100])`，沿用原 TRAIN 的 `edges_logQ` 与原 `b = clip(searchsorted(edges, log(1000q))−1, 0, 7)`。唯一连续条件为

`h = (log(1000q) − (edges[b]+edges[b+1])/2) / ((edges[b+1]−edges[b])/2)`。

边界、单位和计算顺序固定；不重新拟合归一化，不按 DEV 选尺度，不裁剪 h，不删除边界外事件。h 由 float64 原始 q 计算，转为网络 dtype；同一事件的 h 在 ODE 全程不变。SOURCE 与同处理 REAL 使用同一公式和算子。速度场内部的电荷切空间投影保持原样。

## 固定训练和停止点

复用 R53 的唯一平滑脉冲教师、R52 的完整周期与独立末周期匹配、R48 噪声规则、R43 常量和原始暴露流。教师原有全量恒等式检查照常执行。完整周期 94,400 行重复 16 次，再使用独立的 89,600 行末周期；原 SOURCE、REAL 身份支路、所有随机流和总匹配目标出现次数保持一致。初始参数逐张量与原 R48 初始化核对；不得载入 R53 训练后权重。

唯一一次训练从零执行恰好 50,000 次更新，batch=32 SOURCE + 32 REAL 身份，Adam lr=0.0002、betas=(0.9,0.999)、eps=1e-8、无 weight decay，梯度裁剪 5，两个损失权重各 0.5。只保存最终权重，不选检查点、不追加训练或第二个种子。保存两支路损失、h 范围、条件权重梯度和原随机流一致性回执。另核对 R53 的匹配目标流；q 条件是否收到梯度是实现记录，不能代替科学验收。

先按原 128 条 TRAIN 数值样本执行 Heun128 对照 Heun256：median≤0.25 LSB、p95≤1 LSB、preADC 相对 q 误差≤1e-5。不通过即关闭本固定数值配方，不打开 DEV，不搜索其他步数。

## 数值门之后的固定评价

使用原 2000 SOURCE、2000 同处理 REAL、1024 重复噪声、832 源探针、128 guide 扰动，合计 5984 条新输出；原事件顺序、权重及源组成不变。新拟合 HGB 恰好 10 次，密度描述槽 16 个；BASE、旧 R49 和 R53 对照复用已保存结果。统一 ADC 码重建用于所有已量化响应，原始 SOURCE 输入的分箱与指标继续采用未量化波形。全部八个区间和失败密度拟合保留，不以旧 postADC 分母替换原始 SOURCE purehad Q3/Q4 的 213/181。

按原 A/B/C 计算完整五视图、PSD、必需 Q2–7 峰位/峰宽、噪声、源关联、边界和数值门。与 R53 的描述比较使用相同 GPU 平台、初始权重与暴露流；五视图 BA 的配对区间用已保存同一固定划分预测计算，不新增分类器或挑选视图。另在独立进程经可移动推理入口重放 4000 条主样本，要求原位级一致标准。

若 A–C 不全通过，关闭这个固定连续电荷方案、完成负结果交付，再据证据决定新机制，不调尺度或检查点续跑。若 A–C 全通过，冻结本权重后依原协议另行登记 D 的固定任务效用与 E 的 FULL/GAP 验证；只有原 A–F 全部有证据且实际交付完成才结束长期目标。既有 DEV 历史暴露必须披露；本轮不得打开最终 EVAL 或新解码 CAL。
