# R18：由完整仿真波形驱动的无配对响应转换

本任务执行用户2026-10-09的明确纠正：“我们研究题目是怎么把波形从仿真域转向实测域”“让神经网络学习到仿真与实际之间的信号差距实现转换”“因为没有配对域，所以必须采用无配对的学习方式”。整个项目目标仍active。R11–R17只保留为目标密度诊断，不能作为已经完成仿真输入转换的证据，也不再接续其无条件生成器扫描。

## 科学问题与方法

一个真正接收480点G4派生波形的神经网络，能否在没有逐事件实测配对的情况下学习实测响应变化，同时保留源事件的电荷/PSD信息与沉积组成关系？本轮先建立和验证这一直接转换器，不声称唯一物理映射。

采用单向、带源内容约束的无配对波形转换：G(x_sim, z) -> y_real_style。用小型1D残差编码器/解码器或U-Net接收完整480点波形；随机量只提供同一源事件的响应波动。不能把输入压成既有四条件后绕过波形编码器，也不能从R17目标密度先独立抽取一个波形充当输出。允许将从输入本身得到的电荷/幅度作为附加尺度通道；PDG、event_id不得作为网络输入。

以独立抽样的实测波形训练域判别/分布匹配，以同一源波形及其输出之间的多层时序特征对比约束保留内容（1D CUT思想，属于本项目改写，非原论文复现）。加入源电荷排序/相对变化约束与源PSD排序约束；允许PSD有整体或电荷相关域偏移，不把PSD数值恒等作为正确答案。不要求新逆网络或逐点循环恢复随机噪声。可使用同域identity项；绝不将随机抽到的sim与real当作逐点MSE目标。随机输出的组内波动必须与父事件关联保存。

一套预先冻结的模型和损失，单训练臂。执行器在第一次参数更新前保存具体架构、所有损失及权重、优化器、种子、初始化、抽样方式、内部验证选择公式和支持规则；上述常规实现细节直接决定并执行，不等待根代理二次许可。不得根据DEV改损失/架构、追加另一配方或重新抽好看的事件。旧0.15残差上限不是本轮硬约束；选择的输出范围应允许实际域偏移，明确记录。

参考原始方法：CycleGAN说明无配对分布匹配的欠约束问题及循环辅助（https://arxiv.org/abs/1703.10593）；CUT提供单向多层内容对比思路（https://arxiv.org/abs/2007.15651）。不以这些论文保证本数据的物理可辨识性。

## 数据与训练角色

- 源：直接复用R2 `data/G4_TRAIN_CACHE.npz` 中8192个已登记父事件，保留既有6593 TRAIN-fit /1599 internal-val。网络波形输入为现存 `clean_expectation_V` 的480点V波形；这是G4总沉积经既有解析响应核派生的波形，不是新增光学Geant4时序。复用既有2000 DEV父事件，并用完全相同的已存R2构造得到源波形。不得把含噪旧SIM和clean输入混称同一分布。
- 实测：复用R14扩充的21047 TRAIN-fit与既有599内部val；DEV2000用于本轮结束报告。沿用既有人工分组和角色索引。无EVAL、无CAL波形、新原始解码或新G4模拟。
- 两域没有事件配对。源与目标索引/RNG流独立，源父记录贯穿推理与评价。为避免判别器仅利用电荷人口差异，可按旧R3B固定电荷区间共同支持进行独立的同区间抽样；这只是条件抽样，不是配对监督。保持区间外及缺支持计数，最终报告完整人口，不把不支持事件删除后宣称总体成功。
- 源沉积pure-EE、pure-had与mixed按已有edep字段独立报告；另报告PDG22/2112，但不能把incident neutron自动等同pure-had。实测低/高PSD成分只是操作性响应描述，不是已知粒子真值。不为凑实测混合比例重标源事件。
- source-PSD包含既有响应核先验，不能据本轮训练反证这些核已获得物理校准。

## 本轮必要验证

1. 全2000源父事件逐个转换并保存输入、输出、父记录、实际随机量；明确源电荷/PSD与输出的相关和迁移。原始输入作为恒等基线，完整人口的Q–PSD散点按沉积组成着色，报告QC/支持失败。
2. 在相同随机量下交换或替换源波形，输出应跟随源波形发生有意义的变化。选定固定父样本的源电荷比例变化/快慢组分插值属于解析反事实探针，不称新增Geant4事件。记录输入置换、同输入重复和固定源改变噪声三种对照；不能仅以非零梯度证明内容保真。
3. 对pure-EE、pure-had及mixed分别画固定窄电荷区PSD分布；使用有限个固定父事件的重复噪声（最多128父×8次）检验同类输入是否无依据裂成两带，报告每父组内与父间PSD变化。无需靠一次不稳定双高斯拟合断定有/无双峰。全PDG2112混合本身可能有不同沉积机制，单列说明。
4. 复用共同预处理：基线0:100，快积分100:150，总积分100:400，1ns采样，signed PSD=1−Qfast/Qtotal，沿用ADC。比较逐电荷CDF/W1、谷区、合格条件峰位/峰宽，以及波形/噪声副作用；不得只优化或报告FoM。
5. 共同固定C2ST视图、TRAIN/holdout位置和实测对实测参照（最多24个HGB拟合、16个宽度EM）。如某项已能直接复用则不为凑预算重复拟合。分类器近0.5不作为相等证明；报告其训练/留出成绩。
6. 在独立进程用保存模型、真实源输入和实际随机量重放2000主输出一次。推理必须可独立使用，无需训练集或实测目标波形。保存训练轨迹、内部val选择与末点，不按DEV挑结果。

以上是有界原型实验和可证伪检查。匹配总体实测分布与保留源组成可能因两域混合先验不同而冲突；如发生，保留结果并明确指出。不能用源信息丢失换取好看的实测双带，也不能因内容项使输出近恒等就称转换成功。
