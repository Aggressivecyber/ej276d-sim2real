# R39启动前补充：同处理REAL控制的解释与判据

本补充仅覆盖R39主协议第5门的比较对象；输入、模型、损失、系数确定、更新数、所有生成/评价/回放计数、资源预算及其余5门保持原登记。本补充在任何R39科学作业和REAL控制输出之前登记，不重置原截止时间。原协议保留，用本补充记录启动前纠正，不覆盖历史文本。

依据当前`model.py/legacy_model.py`的实际代码，G输出为source-conditioned signal加由z/white/style驱动的electronic，原identity训练使用全零随机量。对已经含采集噪声的REAL输入再使用非零随机量，不具有统计恒等保证；不能把R36目标域扩散修正的RAW恒等容差移为此源域神经G的科学要求。这个判断来自模型定义，尚未观察本轮任何控制生成或评价结果。

原登记两个同处理REAL控制仍全部执行：相同2000 TRAIN_REFERENCE行及相同主z/white/style分别经过冻结BASE G、新G，再与原REAL DEV评价。两者相对RAW REAL–REAL的所有变化仍完整报告，包括完整电压/形状、噪声、Q/PSD、条件峰形；它们只能描述作用，不宣称G对REAL恒等或物理正确。

第5门替为：full493、纯u480、baseline三个视图，新REAL控制减同处理BASE_REAL_CONTROL的配对ΔBA95%上界各<=.10，且点差各<=.01，使用原500次固定分类器留出组bootstrap。RAW比较的绝对ΔBA及区间继续报告，原“相对RAW上界<=.10”不再是此门槛。新门槛只要求更换训练目标没有引入超出原源域G的额外REAL控制失真；若两者都远离RAW，也不得称REAL响应保持、独立采集等效或恒等控制通过。

其余完整源候选验收不降：完整shape/纯u仍相对RAW REAL DEV与BASE判别及R37+.01门槛；PSD/峰位/宽度/噪声/有效密度支持、源组、边界、完整source扰动与6000回放等原要求全部继续执行。无额外拟合、带宽/系数/端点选择或预算扩展。
