# R26：固定训练行的电荷条件批次能否改善完整响应

R25 的 REAL TRAIN 自身分布检验中，混合Q区批次在 physical/pooled-shape 两项上偏好 c=.75，但原分布组合相对 c=1 的差仅 -0.000005812，固定池MC 95%区间[-0.0059466,0.0059350]，不支持整体收缩结论。同区批次的组合差为+0.0290695，[0.0217459,0.0363932]，对这次收缩有明确惩罚。energy参照也惩罚收缩，但它改变距离目标；本轮先检验更直接的训练/验证条件结构差异，不同时替换距离。

三个冻结状态的梯度核对表明，NCE、domain_SW以及已训练D的梯度不能由标量损失大小判断；所有检查批次会触发原clip5，仍不等于Adam更新因果。总G梯度与分项范数和的比值中位约.601/.527/.735，没有全面抵消到零。因此本轮不根据范数删NCE、换GAN、取消裁剪或扫描权重。

本文件可提前准备。仅在R25所有科学作业终止、一次封存且根正式登记R26后，既有Sol-Max执行器开始。继续本机执行，所有源码/数据/缓存/临时文件只写E/D，不SSH、不安装、不新增代理。根负责方向与关键结果，执行器在本轮预算内连续实现、运行、自检、绘图与封存，无需逐步骤审批。

## 一个新训练臂与固定对照

新臂为HOMOGENEOUS_REORDER，历史对照为R23/STANDARDIZED。两者均从R21/GLOBAL_STYLE所选2000步G/reader及R18初D、新Adam开始。沿用R23的STANDARDIZED critic、固定R22 mu/scale、完整480点输入、style/z/white、全部网络和10项G损失公式/系数、batch32、Adam lr .0002/betas(.5,.999)、clip5和1次D对应1次G/reader更新。TILT、标量物理参照、fine常数和原验证定义全部固定。

从R23/STANDARDIZED已经实际消费的2950步中取全部94400行，每一行的source/REAL/bin、原CDF均匀数（若记录）、z[8]/white[480]/style[8]仍绑定原行。源与REAL只共享电荷区，没有事件真值配对。原噪声由保存的初始Generator状态按原每步z→white、独立style的顺序准确重建，禁止把同一seed重新抽取的新顺序称为相同随机输入。

唯一主动变动是行的批次组织与训练顺序：使用完整整数PCG64种子20261009261，按bin=0..7顺序分别随机排列该bin原行序号，切成尽可能多的32行同区块；各区余数按bin顺序拼合为32行尾块，最后将全部2950个块用同一Generator随机排列。94400可被32整除，所有余数均保留，不补样、不丢弃、不重复原行。记录同区块数/余数混合块数、每块bin以及完整行置换；不能声称100%批次同区。原每步3层NCE位置仍按原2950步位置流使用，不能把位置附到重排后的某一个源父。

核对完整原行序号恰为0..94399的一个置换，所有逐行source/REAL/bin及随机变量仍绑定相同原行；报告与历史对照的全程曝光和唯一父数。这是方法比较所需的算法检查，不是文件迁移测试。无需将约181MiB的全white数组额外写盘，可在内存重建并保存原流状态、置换和实际消费摘要；主要推理实际输入仍落盘。

该方法同时改变同批rank/NCE、判别器博弈、梯度方差与时间顺序，不称为只隔离fine损失条件化的因果消融。全程完成时才称行多重集和2950次更新相同，不能称逐步输入相同；若900秒训练上限先到，保留实际置换前缀、曝光差与停止原因，不补跑或另开种子。

## 判断和停止

首先检查新臂是否得到比起点更好的固定所选模型，然后结合预指定的末点比较判断训练有没有改变完整响应，以及J20选择是否与完整响应表现一致。任一J、D分数、PSD单边际或一个C2ST视图改善都不单独构成完整成功；波形/噪声、条件宽度和源内容失败必须保留。

若仍选起点或完整响应不改善，封存这一次条件批次重组结果，不追加新seed、别的batch大小、energy距离、NCE权重或更长训练。根据本轮结果再选择下一项有依据的问题。不能把有限单seed比较推广为条件训练不可能，也不能把末点DEV诊断称为新盲测或由它追溯改选模型。
