# R21：让独立随机变量参与完整源条件信号解码

R18–R20的完整源输入与独立推理接口成立，但同一源父的PSD标准差约.0016–.0022，纯沉积组输出仍为极窄的条件带。R19采样倾斜改善局部中心；R20加入全采样点分布项，细项验证分数下降，完整shape仍.996、基线ACF1距离.338123，中区pure-had谷区比例又到.681159/.230769。增加当前损失未解决条件响应分散。

现有信号路径m(x)在给定源波形时为确定函数，随机变量只进入末端的1mV白噪声加5mV限幅分支。该限幅本身不能证明峰宽不可实现；本轮检验的是一个明确的新随机信号模块：独立style变量进入多尺度信号解码，并用潜变量恢复约束鼓励使用它。方法动机来自无配对多模态转换中的内容/风格分解和潜变量重建（[MUNIT, 2018](https://arxiv.org/html/1804.04732v2)）。本轮是沿现有单向波形网络的适配，内容分布对应仍受R19软先验假设限制，文献不提供本项目的唯一物理映射保证。

项目保持active。本轮只有一个新训练臂 `GLOBAL_STYLE`，对照复用已执行、封存的 R20/FINE，其相同起点、4000步实际流与评价均已保存，不重复拟合旧对照。比较检验“全信号随机调制+潜变量恢复”这一组合，不能拆成对单独容量或单独恢复项的因果结论。

## 保持不变的部分与共同起点

从R19/TILT所选完整 `TRANSLATOR.pt` 和R18 `INITIAL_CRITIC.pt` 开始，与R20/FINE相同；新Adam、lr/betas、batch32、裁剪、全部R20/FINE原损失及权重、TRAIN冻结TILT采样和fine常数均复用。R20/FINE是参考臂，不从它的所选末权重续训。

实际source/REAL索引、Qbin、旧z8/white480和NCE位置序列复用R20/FINE的4000步流；新增style用专用RNG，不能扰动旧流。保存聚合流匹配结果。若时间上限导致少于4000更新，保留实际步数与公共前缀，不能声称完整等更新比较或追加补训。

输入始终为完整480点源波形；h只用于既有采样和明确标注的组成评价，不作为新神经标签。两域独立采样，没有SIM–REAL逐条配对或逐点监督。源6593加载/3753共同区、REAL21047加载/18895共同区的覆盖边界不变。所有原2000主源父事件、支持外计数和原混合比例保留。

## 新增随机信号模块

1. 新style变量s为独立8维标准正态，与旧z和white分开。训练style专用种子20261009211，内部val种子20261009212，主生成20261009213，重复/分解探针20261009214。新增模块初始化专用种子20261009210；初始化不得改变继承的G/D权重或旧批次RNG。
2. 保留完整源编码器与跳接。在64通道瓶颈、32通道d1输出、16通道d0输出各加逐通道仿射调制：H'=H*(1+gamma_s)+beta_s。一个8→128→224的MLP（隐藏LeakyReLU .2）输出三层共224个gamma/beta；最后线性层权重/偏置初始化为零。实际参数取MLP(s)-MLP(0)，故s=0时调制始终为恒等。这里不增加人为电压限幅或重写原物理ADC。
3. 信号分量为S(x,s)=x+.1*mean_head(h_s)，再加原电子随机分支N(h_s,z,white)。旧1mV白噪声、5mV残差限幅和噪声网络保持。S不是对随机s求期望后的“均值”；文件和图中明确称信号分量。N可经h_s间接受s影响，这一耦合需说明。
4. 潜变量读取器仅训练使用：对源x与信号分量S分别按原前100点均值去基线、按max(峰值,.0025V)归一化；截取[100:400]，每5点平均为60维，各60维拼接成120维。读取器MLP为120→128→128→8，两个LeakyReLU .2。它不读基线区、旧z、white、源父ID或真实实测匹配记录。
5. 新项 L_style=mean(abs(E_style(pool(x),pool(S))-s))，系数1.0，与原R20/FINE总损失相加；G与读取器参数联合用上述Adam更新。REAL identity继续使用旧z=0、white=0，并新增s=0。源内容NCE、电荷/排序/正电荷和域损失不减弱；不添加随机源类或粒子标签。

首次参数更新前，用一个固定TRAIN批次确认零初始化新模块对任意两组style均与继承G输出一致，记录pre/post ADC最大误差和逐值结果；只作这个必要结构检查，不另开全数据复算。记录新增参数量、首实际批次L_style及其对调制参数的有限非零梯度。若常规实现错误阻止等价性/梯度，预算内直接修复，原失败保留，不能换配方。

所有结构、系数、RNG及初始化检查在首次更新前冻结。潜变量恢复变好可能来自易解码纹理，不能自动当作正确物理变化；后面的联合波形、纯组成与变化分解必须一起判断。

复用R20相同512 source /599 REAL、旧实际z/white、TRAIN冻结倾斜权重和fine常数/投影，另冻结每个source-val的s。选择量仍是J20=J19_weighted+fine_val，不把L_style加入选择量。step0、每250步、预算末点均评价，最低者选中、同分取早者；保存所选/末权重及读取器权重。原J19weighted、原未加权J、三组fine项和latent重建误差保留轨迹，末点不另做DEV选型。

## 主评价、源保真与随机作用分解

主生成只增加GLOBAL_STYLE的原2000父事件，沿用R20实际source/z/white，并保存新增s。与REAL、SOURCE_CLEAN、R19/TILT、R20/FINE同图。主总体不重加权；TRAIN比例标准化为辅助。七视图固定C2ST新拟合7次（上限12），新宽度描述八区最多8次EM；所有旧参照直接复用。保留固定分区、原生预处理/ADC、QC、CDF、谷区、所有合格/不合格区和成分中心/原宽度/去趋势宽度。区组区间仍条件于检验器，不包含响应训练不确定性。

源组成pureEE/purehad/mixed、入射PDG、source-Q与output-Q分开报告。特别检查既有第3/4 source-Q区pure-had谷区与中心、纯组成条件带是否仍收缩、是否出现由随机style造成的另一离散响应带或源输入被忽略。零跨谷不是合格证据，跨谷事件也不自动证明双峰；需结合完整CDF/直方图、支持与源关联判断，不能把纯组随机拆分以迎合REAL混合比例。

随机作用预指定分解，总新增重复输出最多4096：

- 复用原128父×8次联合重复（1024），同一组实际旧z/white，加固定新s序列。
- 按原128父数组次序选前16个pureEE、前16个purehad，共32父；源和旧z/white固定为其一个实际参考draw，只改变s各32次（1024）。
- 同一32父，源与s固定为一个实际参考draw，只改变旧z/white各32次（1024）。

实际共3072个规划重复输出，源父数不增加为独立G4事件。分解结果报告PSD、总电荷、信号分量/电子分量的逐点变化与波形RMS、组成分组及Q覆盖；从保存载荷形成图，不做新拟合。对比“仅style变化”与“仅电子噪声变化”是否产生有意义的信号变化，同时检查中心、波形、噪声和源信息损失。实测跨事件宽度不是同一物理父事件重复宽度真值，不据其强行指定某一父的随机SD。

原源探针最多1024：同输入同全部随机量、固定随机量替换源、固定源改随机量、解析幅度/形状探针继续使用已修正父索引语义；新增style的来源/参考行明确记录。非零敏感性不是物理校准。推理不得调用style读取器、真实实测事件或TRAIN缓存来生成输出。

新独立进程仅用所选模型、实际source/s/z/white和静态推理常数重放2000主输出，保留ADC前后逐值结果及源身份。主评价如果只增加宽度而破坏单源内容/纯组结构、细波形或噪声，仍记失败；没有提升就封存，不追加style维度、损失权重或调制强度扫描。
